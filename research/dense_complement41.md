# 41 点无三角稠密补图的独立分类

本文件只使用本次推导，不引用网络或已有相关证明。分类已由另一研究代理独立逐项复核（见 `dense_complement41_review.md`）。下文最后一节结合此前的24度强团引理，排除全部分类的冲突来源。这仍不是原问题的完整解答。

## 定理

设 J 是 41 个顶点的无三角简单图，最小度至少 16。若 J 非二部，则它可分成五个非空独立集 X_0,...,X_4，所有边只连接下标模 5 相邻的两集。旋转和反向下标之后，集大小只有三类：

1. (8,8,8,8,9)，相邻集之间全连；
2. (9,9,7,7,9)，相邻集之间全连；
3. (9,9,8,7,8)，相邻集之间全连，但两个相邻的 9 点集之间可以删去一个匹配。

匹配可以为空。本定理的证明独立于“这些图是否具有原图冲突来源”。

## 1. 先找到一个五圈

取最短奇圈 C，长度 l。它没有弦。任意圈外顶点至多有两个 C 邻点：若有至少三个，沿圈相邻邻点间的间隔均至少 2；这些间隔总和为奇数，故某个奇间隔至多 l−4。该段加上到圈外顶点的两条边给出更短奇圈，矛盾。

因此

16l ≤ Σ_(v∈C) d(v) ≤ 2l+2(41−l)=82。

无三角且 l 为奇数，故 l=5。

将 C 依次写为 c_0,...,c_4。每个有两个 C 邻点的顶点属于唯一 X_i：其 C 邻点为 c_(i−1),c_(i+1)。特别地 c_i∈X_i。其余顶点分为 Y_1（一个 C 邻点）与 Y_0（没有 C 邻点）。记 a_i=|X_i|，b_i=|N(c_i)∩Y_1|，p_i=a_(i−1)+a_(i+1)。

两类 X_i,X_j 若下标相同或相差 2，就共有一个 C 邻点，故其间没有边；所以 X 之间只能在相邻类连边。又 c_i 恰好邻接 X_(i−1)∪X_(i+1)∪(N(c_i)∩Y_1)，故 d(c_i)=p_i+b_i。

对五圈度数求和可得

80 ≤ Σ d(c_i)=82−|Y_1|−2|Y_0|。

所以异常点只有以下四种情况：空集；一个 Y_0；一个 Y_1；两个 Y_1。

以下用到的大小上界为 a_i≤9。可直接解五个方程 p_i=a_(i−1)+a_(i+1) 验证：

* 一个 Y_0 时，Σa_i=40，p_i≥16，总和为80，所以 a_i=8。
* 一个 Y_1，设其唯一 C 邻点为 c_k。此时 p_i=16+e_i−1_(i=k)，其中 e_i 为非负整数且 Σe_i=1。由以 8 为基准的五个方程，每个 a_i−8 属于 {−1,0,1}。
* 两个 Y_1 时，p_i=16−b_i，Σb_i=2。解方程得到（旋转/反向意义）(7,7,9,9,7)、(7,7,8,9,8) 或 (8,8,8,8,7)。

这些方程的逆也可以统一写为：若 q_i=p_i−16，则

2(a_i−8)=q_i+q_(i−1)+q_(i+1)−q_(i−2)−q_(i+2)。

## 2. 排除单个 Y_0

设异常点只有 y∈Y_0；此时每个 a_i=8。记 S_i=N(y)∩X_i，s_i=|S_i|。因为 y 不邻接任何 c_i，s_i≤7。

任取 x∈S_i。它只能邻接相邻两集中的 16 个点以及 y；故为了达到度数16，它在这16点中至多漏掉1点。S_i 与 S_(i+1) 之间不能有边（否则和y成三角）。因此若相邻的 s_i,s_(i+1) 都为正，它们都至多1。

若所有 s_i≤1，总度数至多5。否则某个 s_i≥2，其两侧 s 必为0；剩下两类彼此相邻，或者仅一类非空（总数至多7+7=14），或者各至多1（总数至多7+2=9）。均违反 d(y)≥16。因此 Y_0 情形不可能。

## 3. 一个 Y_1 可以重新归类

设唯一异常点 y 的 C 邻点为 c_k。由于 y 与 c_k 相邻，y 不能邻接 X_(k−1) 或 X_(k+1) 的任何点，否则形成三角。因此它的邻点只能在 X_k,X_(k−2),X_(k+2)。后两集的下标相邻。

若 y 在后两集均有邻点，记其数量为 s_−,s_+。对其中任一 y 邻点 x∈X_i，潜在度数至多 p_i+1；最小度16说明它在相邻两集至多漏掉 p_i+1−16 个点。由上一节的表达式，i≠k 时该数为 1+e_i，且所有 e 的和为1。两边的 y 邻点之间全不相邻，所以 s_−+s_+≤3。于是 d(y)≤a_k+3≤12，矛盾。

故 y 只能邻接 X_k 和后两集中的至多一集。将 y 放进这两集之间的类型 X_(k+1) 或 X_(k−1)，便仍然保持“所有边只在相邻类之间”的五集划分。若后一类均无邻点，也可任取这两种类型之一（实际上最小度已排除此情形）。

## 4. 两个 Y_1 也可重新归类

设异常点 y,z；y 的唯一 C 邻点为 c_k。仍然只有 X_k,X_(k−2),X_(k+2) 可能邻接 y，另外可能有边 yz。现在 p_i=16−b_i≤16。

若 y 在 X_(k−2),X_(k+2) 均有邻点，则任一这样的邻点在其相邻两集至多漏掉2点（它在异常集最多有2个邻点）。所以这两个邻点集合各至多2，得到 d(y)≤9+2+2+1=14，矛盾。

因此 y 必须选择 X_k 和另一个 X_(k+2ε)，ε∈{−1,1}。后一集中的 c_(k+2ε) 不是 y 邻点，于是

16 ≤ d(y) ≤ a_k+a_(k+2ε)−1+1_(yz∈E)
                 =16−b_(k+ε)−1+1_(yz∈E) ≤16。

各处均取等。因此 yz 为边，b_(k+ε)=0，y 邻接 X_k 全部点以及 X_(k+2ε) 中除 c_(k+2ε) 外的全部点。将 y 的新类型定义为 k+ε；对 z 同理。

这两个新类型必须相邻：在五圈上，两种“邻接两类”的模式若类型相同或相差2，它们至少共享一个 X 类。每个 X 类至少7点，而 y,z 在该类各至多漏掉一个点，所以会有公共邻点，和 yz 构成三角，矛盾。故两个新类型相邻，把 y,z 加到相应类后，边 yz 也符合只连接相邻类的规则。

至此所有情形都得到五个独立集的划分，且边只连接相邻集。

## 5. 求解最终类大小与缺边

现在没有异常点，记最终大小仍为 a_i。每类非空，且最小度给出 p_i=a_(i−1)+a_(i+1)≥16。又 Σa_i=41，所以写 p_i=16+e_i 后，有 e_i≥0、Σe_i=2。

由上述五方程逆式，只有三类：

* 一个 e_i=2，其余0：类大小为 (9,9,7,7,9) 的旋转；
* 两个相邻 e_i=1：类大小为 (9,9,8,7,8) 的旋转；
* 两个不相邻 e_i=1：类大小为 (8,8,8,8,9) 的旋转。

对 x∈X_i，它至多能漏掉相邻类中的 e_i 个点。任何缺边的两个端点类型都必须 e>0。因此第一、第三种情况不能有缺边；第二种的缺边只能连接两个 e=1 的相邻类，且每点至多属于一条缺边，即缺边构成匹配。这两个类均有9点。

定理证毕。

## 6. 排除所有独立数至多2的21临界冲突图

设 H 是21色顶点临界冲突图，且 α(H)≤2。它的补图 J 无三角。记 n=|V(H)|、c 为 J 的分量数。

团划分数 θ(J)=21，且删任意点后为20。因为无三角，θ(J)=n−ν(J)，所以 ν(J)=n−21，删除任意点不降低最大匹配数。`critical25.md` 第4节的自证匹配引理表明，每个 J 分量都是因子临界；因此

n=2ν(J)+c=2n−42+c，亦即 c=42−n。

于是 n≤41；已完成的小规模排除给 n≥26。又 Δ(H)≤24，所以 δ(J)≥n−25≥1。任取 J 分量的一条边，其两端邻点集不交（J无三角），故该分量至少有2(n−25)个点；因子临界分量为奇数阶，故至少有2n−49个点。

因此 n≥(42−n)(2n−49)。但对26≤n≤40，右端减左端为

120−2(n−33)^2≥22>0，矛盾。

唯一剩余情况为 n=41、c=1。此时 J 连通、因子临界，因而非二部：奇数阶二部图中删除较小部分的一个点，不可能有完美匹配。又 δ(J)≥16，故适用本文件的分类。

三类分类均包含一个大小至少8、每点 J 度恰为16的独立簇：

* (8,8,8,8,9) 中取9点簇；
* (9,9,7,7,9) 中取下标1的9点簇；
* (9,9,8,7,8) 中取下标2的8点簇，允许删除的匹配不影响它。

该簇对应 H 中至少8个两两相邻且度数均为24的点。对应原边在整个原图中也恰好有24条冲突边（H中已达通用上界）。这与 `critical_support.md` 严格证明的“冲突度24的强团至多7条边”矛盾。

所以不存在 α(H)≤2 的21色临界冲突图。

**任意规模推论。** 对最大度4原图任取边集 F，若 F 中没有3条两两不冲突的边，则 F 按原图完整冲突关系可用20色。否则取一个顶点极小的非20可染冲突诱导子图，就得到被排除的21临界 H。每个颜色类至多含2条边，因此进一步有 |F|≤40。

等价地，任何41条原边都包含3条两两不冲突的边。这里始终保留原图全部见证边，未将删除见证边后的较弱冲突关系混用。

这个结论解决了独立数至多2的全部规模，但仍未排除独立数至少3的21临界冲突图。
