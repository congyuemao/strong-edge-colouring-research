# 高点延拓约束的带权二点保护接口

这是对 critical_five_independent_high.md 的独立检查和后续补充。一般“最大度五、五度点独立、K5-free 且无两个 K4 共三点则四染”仍未证明。本文件只给出一种可以处理混合低分量的充分条件。

后续 structural 与根代理已证明更强的 weighted_nae_three.md：每超边端权至少三、每点端权至多五的任意非单色约束可四色满足。本文件作者已独立全文核验通过。该结果涵盖本文件保护对引理及其混合应用，并进一步处理三个以上端点的保护集合；本稿保留为更短的密度特例及独立复核记录，不把被涵盖的数值或子类重复记作新进展。

## 1. 独立审核记录

已逐项核验该文件第 2 节的加权超图引理。顶点极小反例中每点至少关联四条超边，由端权总和至多五，单个关联权至多二。选每条超边两个端点、每顶点使用至多三次的容量割，确为

    2*(|E|-|E'|)+sum_v min(3,d_E'(v)).

权估计保证它至少总需求 2|E|；整数增广流给合法端点选择，所得最大度三图可贪心四色。

也核验了第 3 节 K4 桥树接口：固定父端颜色后，三个剩余至少二元的列表仅在同一个二元集时失败；向父传递的可用色集因而只能是全四色或单色。根 K4 唯一失败是四个同禁色，递归回代恰等价于全部高邻同色。

## 2. 带权二点保护引理

设变量集 T 上有若干约束 C，关联 (C,t) 的正整数权为 m(C,t)，且每个变量的关联总权至多五。

假设每个约束都可选两个不同关联变量 a_C,b_C，满足：

* a_C、b_C 颜色不同足以使该约束成立；
* m(C,a_C)+m(C,b_C)>=3。

则这些约束可以同时用四种颜色满足。

证明：在 T 上连所有选定的对，重复边只保留一条。对所得简单图 Y 的任意非空诱导子图 Y[S]，每条边选一个产生它的约束作见证。同一个约束只产生一条边，因此见证不重复。每边两端见证权之和至少三，而每个顶点全部可用端权至多五。故

    3*|E(Y[S])| <= 5*|S|.

平均度至多 10/3，小于四，所以 Y[S] 有度至多三的点。递归删去这种点，再倒序贪心四色，即可给 Y 四染。每个约束的保护对异色，故所有约束同时成立。

这比把辅助图再归约到“独立五度点”目标类更直接：不需要递归假设未证主命题。

## 3. 在低分量延拓中的应用

设 X 的高点集 T 独立，T 中各点度至多五，其余点总度恰为四。给 T 四色后，希望独立染每个低图分量 C。令 m(C,t) 为 t 到 C 的边数，自然满足每个 t 的端权总和至多五。

### 3.1 K4 桥树

若 C 是若干不交 K4 以桥连成的树，原稿已经证明其不能延拓恰在全部高邻同色时。

因此，只要 C 有一个高邻关联权至少二，选该点与任一另一高邻，就得到权和至少三的保护对。K5-free 和度数条件保证至少两个不同高邻，见原稿。

如果全部高邻都只接一个端口，本接口不能给权和三的保护对；原稿的加权超图引理能够单独处理这些约束，但还不能直接与本节其他类型无条件混合。

### 3.2 一个孤立奇圈低分量

设 C 是奇圈，且每个圈点的两个其他邻点都属于 T。把每个圈点的这两个高邻连成一条边，得到 T 上没有自环的多重图 R_C；不同圈点可给相同边。

每个圈点的剩余列表至少二元。奇圈不能从这些列表染色，当且仅当全部列表是同一个二元集。其自证是：若有相邻两点列表不同，给其中一点用对方列表没有的颜色，再沿删点后的路径贪心，最后邻点保留一色；若所有列表相同但含至少三色，奇圈也可三染；同一个二元表在奇圈上确实不可染。

所以 C 不能延拓恰在以下情形：R_C 的每条边都在其两端使用同一个固定的、由两种不同颜色组成的无序颜色对。

若 R_C 有非二部的连通分量，这种情形永远不可能，C 对任意高点颜色都能延拓。

若 R_C 中两个高点位于同一个连通二部成分的同一侧，且它们颜色不同，则该成分不能全部只用同一个异色对，故也是 C 的保护对。这里 m(C,t) 恰为 t 在整个 R_C 中的重数度。

特别地：

* 如果 R_C 含一个连通二部成分，其简单支撑不是星且两侧均至少两个点，则每侧都有一个重数度至少二的点。选这个点与同侧另一点，得到权和至少三的保护对。
* 如果某个星形多重成分至少有两个叶点，且某叶点重数度至少二，选该叶与另一叶也成立。例如三角低分量的星叶重数 (2,1) 可以这样处理。

同一分量中的两侧不能任意混选，来自两个不同连通成分的点也不能直接当成这样的保护对：失败双色允许它们交换两色的方向。

### 3.3 任意混合的一个闭合特例

若每个低图分量都是上述 K4 桥树或孤立奇圈，并且每个并非自动安全的分量都具有 3.1 或 3.2 节的权和至少三的保护对，则 X 可以四染。

先由第 2 节同时给高集 T 四色，使全部保护对异色；然后各低分量都可独立延拓。这是任意规模的结论，不要求各分量的高邻集合不相交。

## 4. 仍未覆盖的情况

没有权和三保护对的典型约束包括：K4 桥树的所有高邻都只出现一次；奇圈高邻多重图全部成分均为简单星，或只有两个端点的平行边成分等。一般低图分量还可能把奇圈和 K4、桥混在同一块树中，本文件未推导那类完整接口。

因此本结论不能与原稿第 2 节未经证明地拼成一般四染结论。它提供的是一个新的统一充分条件，并将其权预算与尚未处理的分量明确分开。
