# 高围长匹配冲突图中四团的交叠

本文件的几何结论均为纯数学证明，适用于任意规模。设G无三角形和四圈，M为一个匹配，Q为M的冲突图。最大度4只在应用到主问题时需要。

## 1. 同端角与四团上的一个置换

任意两条冲突的匹配边之间恰有一条原图见证边。若有两条见证，它们共端时与其中一条匹配边组成三角形，不共端时与两条匹配边组成四圈。

Q中三角形在每个顶点的两条见证边，或者落在相应匹配边同一端点，或者落在不同端点，分别称同端角与异端角。如果三个角中有s个异端角，三个见证和相应的s条匹配边组成一个长度3+s的原图圈。因此每个三角形至多一个同端角。

在Q的一个K4中，每个顶点有三条见证，至少有一对同端，故四个顶点至少贡献四个同端角。但四个三角形合计至多四个。所以每个三角形恰有一个同端角，每个顶点的见证恰按2+1分到两端。

对K4中的顶点v，令f(v)为落在单独端点上的那条见证所通向的邻点。显然f(v)不等于v。删去w所得三角形在v处同端，当且仅当f(v)=w。每个三角形恰有一个同端角，故每个w恰有一个原像，f是无固定点的置换。

若f由两个交换组成，记作(12)(34)，那么见证圈1−3−2−4−1的四个角全部同端，原图出现四圈。因此f必为一个有向四圈。

## 2. 三角形最多包含于两个四团

设三角形abc的唯一同端角在a，且它分别与x、y组成四团。两个四团上的置换都满足f(a)=x或y。

在abcx中，四圈置换只有两种：

* 正向：a→x→b→c→a；
* 反向：a→x→c→b→a。

abcy同理。如果两者均正向，见证圈a−x−c−y−a在四点全部同端，给出原图四圈。若两者均反向，则a−x−b−y−a给出原图四圈。因此两个置换必须方向相反。

若同一三角形属于三个四团，其中两者必同向，矛盾。因此：

**Q的任意三角形至多属于两个四团。特别地，Q不含K3与三点独立集的完全连接图作为子图。**

最后一句甚至不要求三个外点相互独立，因为这里只使用三团与外点间的边。

## 3. 两个共三角形的四团强迫Petersen删边块

设两个方向相反，具体为

a→x→b→c→a，及a→y→c→b→a。

将五条匹配边的端点分别记为a0a1、b0b1、c0c1、x0x1、y0y1。可按同端角选择端点标签，使九条见证恰为

```text
a0-b0  a0-c1  b1-c0
a1-x0  b0-x1  c0-x0
a1-y0  b1-y0  c1-y1
```

它们加上五条匹配边给出一个10点14边子图。以下映射将它明确识别为二元子集模型的Petersen图删去12−34：

| 端点 | 二元子集 |
|---|---|
| a0 | 13 |
| a1 | 24 |
| b0 | 45 |
| b1 | 23 |
| c0 | 14 |
| c1 | 25 |
| x0 | 35 |
| x1 | 12 |
| y0 | 15 |
| y1 | 34 |

逐条检查上面14条边的两个二元子集不交；Petersen模型总共15边，余下唯一边是x1y1，即12−34。

事实上在无3/4圈原图中，这个10点子图要么是诱导Petersen删边块，要么补入x1y1成为诱导Petersen。因为删去12−34以后，其他任意非边的两端仍然距离至多3，不能再添加原图边。原先长2路径因删边而消失的非边只有四对；它们的替代长3路径为

```text
12-35-24-15
12-45-13-25
34-15-24-35
34-25-13-45
```

其余非边的原Petersen长2路径不经过被删边。只有12与34本身距离4。

## 4. 可约块的应用接口

Petersen块的8列表延拓证明见petersen_reducibility.md。Petersen删边块需要的内部列表下界为：四个顶点5色、八个顶点7色、两个顶点8色；其冲突图有74边。

根代理给出的图多项式系数证书，已由本代理在petersen_minus_independent.py中从原图重新构造并独立用整数求和复现：目标指数

```text
4,4,4,4,5,6,6,6,5,6,6,6,6,6
```

之系数为12240，非零；各指数不超过对应列表大小减一。具体列表定理及自证插值推导见petersen_minus_reducibility.md，已完成独立逐节审查。

引用该已核验系数及其列表插值引理，以上第3节给出：**无3/4圈的21临界支撑图中，任意匹配的冲突图中两个K4不能共用一个三角形。**

## 5. 每个匹配冲突顶点至多属于两个四团

这里使用最大度4，故Δ(Q)≤6。结合第4节的临界禁形，固定Q的一个顶点z。其邻域至多有6点，邻域中的三角形两两不能共边，否则加上z会得到两个共三角形的K4。

若邻域包含三个三角形，它们两两交集大小至多1。三个三角形合计有9个顶点位置，却只能使用至多6个顶点，故三个两两交集必须各恰有一点，而且这三个交点不同：若三角形共同经过同一点，至少需要7点。

三个不同交点又彼此相邻，因为任意两个都位于原先的某个三角形中。于是它们组成一个新的三角形，且与原先每个三角形共用一条边，矛盾。

因此z的邻域至多两个三角形，即**每个Q顶点至多属于两个K4**。这些K4可以只共一个顶点或者共一条边；目前没有证明这两种交叠全部可约。

上述结论尚不足以证明匹配冲突图5可染；一般6临界图的低度块及高阶部分可能没有这样的四团重叠。本文件不作这一步推断。
