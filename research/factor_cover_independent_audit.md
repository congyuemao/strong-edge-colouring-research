# 二重、三重置换与四重循环覆盖的独立审查

2026-10-09。审查对象为 factor_cover_search.md、三个生成脚本及四个 JSON 证书。本审查没有使用互联网。

**结论：覆盖范围论证与全部证书通过独立核验。** 独立脚本 factor_cover_independent_audit.py 不导入原生成器、冲突图构造函数或染色器；结果保存在同名 JSON。以下说明纯数学覆盖理由与有限计算分别证明了什么。

## 1. 为什么只检查基图简单四圈足够

覆盖映射在每个顶点邻域上是双射。若覆盖图中的游走投影后立即沿同一基边折返，则两次使用的覆盖边必为同一条，因此覆盖游走也立即回到前一个顶点。简单圈不允许这种折返，包括圈首尾处的循环折返。

在无环、无重边的简单基图中，长度三或四的循环非折返闭步必为简单圈：相邻顶点不能相同；长度三的非相邻重复即首尾之外的退化；长度四若有其余重复，只能是相隔两步的顶点相同，形成立即折返。因此覆盖中的三圈或四圈不可能投影到更复杂的带重复闭步。

本基图没有三圈。独立脚本允许游走重复顶点，从每个基点枚举所有长度三、四的循环非折返闭步，得到三圈闭步数 0，四圈闭步数 176；四圈闭步的四个顶点全部互异，按旋转和逆向归并后恰为 22 圈。这些圈也逐一与文稿的两族公式核对一致。

沿一条基图简单四圈，任取初始纤维点后其提升唯一；只有回返置换固定该点时闭合。因基图圈上四个顶点互异，该闭合提升确为简单四圈。故 22 个回返置换全部没有不动点，是覆盖围长至少五的充要条件。

## 2. 纤维规范化不遗漏

若基边 u→v 的置换为 π_uv，把纤维旧标签用置换 g_u、g_v 换成新标签后，新边置换为 g_v∘π_uv∘g_u^{-1}。从 g_0=id 出发，依次令 g_{i+1}=g_i∘π_{i,i+1}^{-1}，便把红路径 0→1→…→10 的十条置换全部变为恒等。

其余红闭边和十一条蓝边仍自由，故有十二个自由置换。此操作只重新命名原图顶点，保留红因子、围长与染色性质；无需假定覆盖连通。固定起始纤维标号后规范化是确定的，不过不同规范化赋值仍可能给同构图，文稿的实例数是赋值数。

二重置换全部属于两元素群。三重置换允许整个 S3。四重循环电压情形中初始置换均为平移，以上 g_i 也均为平移，因此仍留在循环族内。四重循环族的结论不能推广为全部 S4 置换覆盖。

## 3. 三重置换的代数与符号筛选

F3 上的六个映射 x↦s x+b（s=±1，b∈F3）互不相同，故恰覆盖 S3。s=1 对应三个偶置换；s=-1 对应三个奇置换，每个都恰有一个不动点。无不动点的置换只有 s=1、b≠0 的两个三循环。

逆向经过一条边时，其仿射置换为 x↦s x−s b。因此原脚本构造回返线性形式时，每一步把已有系数乘 s，正向增加 b，逆向增加 −s b，是正确的。首先要求各四圈符号积为 +1；独立遍历十二位符号的全部 4096 种赋值，确实只剩 0 与 255 两种掩码。

这两种符号下再分别枚举 3^12 个平移赋值，已经覆盖全部 6^12 个规范化置换组合中可能无四圈者。不能只枚举全正号的循环子族而宣称检查全部三重覆盖。

原代码的单变量传播安全：一个非零线性形式只剩一个变量时，恰排除一个使其等于零的取值；F3 的非零系数自身为逆元。四阶循环情形虽在非域 Z4 上计算，但每个基圈中的自由基边仅出现一次，系数只能为 ±1，依然可逆，因此对应传播亦安全。

## 4. 与生成器不同的独立枚举

独立脚本不建立原生成器的线性形式，也不执行单变量域传播。它按十二个变量依次分支，只在一个四圈所用变量全部确定后，直接沿有向基边复合置换及逆置换，检查每个纤维点是否固定。一个被拒绝的长度 i 前缀，计入其全部 p^(12−i) 个后缀；被保留的完整赋值计入 1。各族的计数总和严格等于 p^12。

| 族 | 覆盖的平移赋值数 | 独立前缀节点数 | 完整解数 |
|---|---:|---:|---:|
| 二重 | 4096 | 31 | 0 |
| 三重，符号 0 | 531441 | 1651 | 0 |
| 三重，符号 255 | 531441 | 1651 | 6 |
| 四重循环 | 16777216 | 64365 | 8184 |

独立完整解集合与原 JSON 的赋值集合逐项相等，不只比较解的总数。三阶循环文件也和符号 0 分支对照一致。

## 5. 原端点证书检查

对 6 份三重置换、8184 份四重循环证书，独立从基边表及显式置换表重建每条原边，并检查：

1. 顶点数正确、没有环或重边，每个原顶点度数恰为 4；
2. 红边数等于顶点数，每个原顶点红度数恰为 2，因此红边确为 2 因子；
3. 每对相邻原点没有共同邻点，故无三角；任何点对不能在两个不同原点的邻集中同时出现，故无四圈；
4. 对每对红边，直接比较它们四个端点以及完整原邻接表，按用户定义判断冲突，并核对冲突边颜色不同；全部红冲突度也再次核对为 12。

三重证书中 4 份使用 7 色、2 份使用 8 色。四重循环证书的 5、6、7、8、9 色使用数分别为 48、2035、5208、878、15，全部一致。所有记录都未启动后备十色回溯。这里验证的是显式颜色表，不声称这些使用数是图的最小染色数。

## 6. 二重覆盖的额外纯数学排除

事实上二重族无高围长实例无需计算：基点 0 与 8 有三个共同邻点 1、4、7，构成 K_{2,3}。从覆盖中一个固定的 0 纤维点出发，沿这三条长度二路径各得到一个 8 纤维终点。终点只有两个可能，至少两条路径到达同一点。两条路径的中间点属于不同基纤维，故它们的并是覆盖图中的简单四圈。

等价地，三个基四圈 (0,1,8,4)、(0,1,8,7)、(0,4,8,7) 的二元电压方程相加左端为 0，但若都消除四圈则右端为 1，矛盾。

本审查只排除这些完整指定覆盖族作为固定因子十一色反例；它不证明一般高围长四正则图的任意 2 因子都可十染。
