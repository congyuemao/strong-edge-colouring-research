# 联合 O9 障碍的两个奇圈可以同时修复

日期：2026-10-09。任意规模纯证明。根代理与结构代理已分别独立核验核心论证；下文将全部接口和适用边界写全。

## 1. 精确假设与结论

沿用 `factor_girth_six_ten.md` 的背景：G 四正则、围长至少六，F 为完整二因子，H 为 F 的强冲突图。选择最小 `(4,4,2)` 势、再最少 C 奇圈的分区 A、B、C。

设来自两个不同 C 奇圈的点 u、w，与七个 A 点形成诱导九点图：

* a,b,c,d 构成高 K4；
* a,b,u,v 构成另一 K4；
* c,d,w,z 构成第三 K4；
* x 邻接 u,v,w,z；
* 除上述边外，九点间没有其他边。

也就是 `joint_o9_rotation.md` 中的联合 O9。这里 a,b,c,d,u,v,w,z,x 都是 H 的点，即原 G 的不同 F 边。

**结论。** a、b 中可以选择一个，记为 h，使

    H[(A−{h})∪{u,w}] 可以四色，
    H[B∪{h}] 可以四色。

把这两部用不相交的四色染色，第三部恰为原来的 `C−{u,w}`。因此原 u、w 所属的两个奇圈同时被切开，且不产生新 C 圈。若原 C 只有这两个奇圈，就得到 H 的完整十色染色。

该结论不预设一次可四色插入一定保持原势或原最大度；最后得到的是两个四色可染的部。

## 2. 两个零势旋转都合法

由最优分区的饱和邻点接口，a、b 的三部邻数都是 `(4,5,3)`。分别交换 u 与 a、u 与 b，均为零势；两次交换分别产生新的最优分区。若其中某次减少奇圈数，就已经违反原来的次级最优性，所以它必须保持奇圈数。

交换 u 与 a 后，记

    A_a=(A−{a})∪{u},
    C_a=(C−{u})∪{a}.

B 完全不变。u 的原奇圈已被切开，唯一新增 C 点是 a，故必须有一个包含 a 的新奇圈补上。另一个包含 w 的旧奇圈不变：若 a 邻接该圈的任何点，交换后该点的 C 度就由二升为三，而它没有失去 u 这个邻点，因为两个旧 C 分量不同。这违反新最小势分区的 C 度上界。

对交换 u、b 的状态完全相同。因此在这两个分别考虑的状态中，a 或 b 都是某个坏 C 奇圈上的点；单点插入、高团临界核分类等接口仍然适用。

`joint_o9_rotation.md` 第 3 节已经独立证明

    H[A_a∪{w}] 可以四色，
    H[A_b∪{w}] 可以四色。                           (1)

其证明利用原三个 K4 对应的蓝三边路径：若旋转后 w 仍阻塞，则新 O9 再给两条蓝边，闭合一个蓝五圈，违反 G 的围长六。

## 3. 至少有一个旋转代表可以插入 B

a、b 是同一个完整 F 二星的两条边。这由原两个 K4 `a,b,c,d` 与 `a,b,u,v` 共享恰两点，以及围长六的 K4 端点分类得出。

把这两条原 F 边写为

    a=s alpha,   b=s beta.

在交换 u、a 后，b 仍在 A_a；交换 u、b 后，a 仍在 A_b。两个状态中的 B 集合与原分区完全相同，且始终有

    d_B(a)=d_B(b)=5.                                (2)

反设在各自旋转后，a 和 b 都不能插入 B 四染。由五度高点成团的唯一 O9 分类，每个失败点在其 B 核中必为高点，且由一条 F 伴边和其共享原端点的两处蓝邻点 F 二星，给出五个 B 邻点。

a 的 B 核不能使用原端点 s，因为 s 处除 a 外唯一的 F 边是 b，而 b∈A_a。所以这个核必须使用 a 的另一端 alpha。令 h_a 是 alpha 处不同于 a 的另一条 F 边，则

    h_a∈B，alpha 的两处蓝邻点的四条 F 边也全部在 B。

这五条边已经用满 (2) 中 a 的五个 B 邻点。

同理，b 的失败核必须使用其另一端 beta，迫使 beta 处不同于 b 的另一条 F 边 h_b 属于 B。

但是 h_b 也与 a 冲突：原边 b=s beta 连接 a 的端点 s 与 h_b 的端点 beta。因此它应是 a 的又一个 B 邻点。h_b 不属于刚才 alpha 一侧的五条边：围绕 F 根边 a 的十二邻点分解中，它是沿另一端的 F 伴边 b 再继续一步所得的边；无三角形、无四圈保证它与 alpha 的 F 伴边和四条蓝星边互异。

于是 a 有至少六个 B 邻点，与 (2) 矛盾。

所以两次旋转中至少有一次，其旋转代表可以插入 B。交换 a、b 的名称后，不妨取为 a，即

    H[B∪{a}] 可以四色。                             (3)

## 4. 两部独立染色，两个原奇圈同时消失

选择上一节的 a。由 (1)，`A_a∪{w}=(A−{a})∪{u,w}` 可以四色；由 (3)，`B∪{a}` 可以四色。这两图的顶点集不交，因此它们的四色染色可以使用不同的四色集，彼此之间的 H 边不会造成颜色冲突。

剩下的点恰为

    C−{u,w}.

其中 u、w 的两个原奇圈分别变成路径，其余原 C 分量保持原状。没有任何新点留在 C，所以不产生新奇圈。

若原 C 恰有两个奇圈，则剩余 C 全是路径或偶圈，可以用另两色，合计十色。这证明第 1 节的结论。

## 5. 仍然未解决的同步问题

该修复只针对已经找到上述联合 O9 形状的一对不同 C 奇圈。它不说明任意两个单独可插入的点在联合失败时都必产生这种 O9；联合插入后，旧 A 低度点可能同时升度，五度点未必成团。第 6 节证明两个代表的联合图仍然最大度至多五；三个以上代表不能直接沿用该界。

若还有其他 C 奇圈，虽然本文确实同时切开了指定两个圈，但所得两大部只知道四色可染，不再保证是原最小势分区，也不再保证最大度四。因此不能未经证明反复应用本命题处理全部奇圈。

当前新增的是一个真正的两圈联合修复，不是一般围长六十色定理，也不是原二十色问题的完整证明。

## 6. 一般两个代表联合失败时仍有最大度五

这是下一步分类可用的独立接口，不假设已出现 O9。取任意两个不同坏 C 奇圈上的点 u,w。原 A 四度点不可能同时邻接这两个圈，见 `factor_girth_six_synchronization.md` 第 2 节；因此在 X=H[A∪{u,w}] 中，这些点最多升到五度。原 A 三度点即使同时邻接两代表，也只升到五度；原 A 度至多二的点升后至多四度。u,w 各有五个 A 邻点，且彼此不相邻。故 X 的最大度至多五。

X 的五度点恰来自三类：

* 两个新点 u,w；
* 各自的旧 A 四度邻点集合 S_u、S_w；二者互不相交，并各与相应新点组成团，大小各至多三；
* 同时邻接 u,w 的旧 A 三度点。

这不保证所有高点构成一个团。若 k=|N_A(u)∩N_A(w)|，则共同邻点中没有旧 A 四度点，且

    |S_u|,|S_w| <= min(3,5-k).

于是 X 的五度点总数至多

    2+k+2 min(3,5-k) <= 10.

若 u、w 各自都可插入 A，而联合不可四色，任一顶点极小的非四色诱导子图 Y 必同时包含 u,w。Y 内两者的邻域不能互相包含：例如若 N_Y(u)⊆N_Y(w)，先四色染 Y-u，再让 u 取 w 的颜色即可（u,w 不相邻），与临界性矛盾。

以上条件尚不足以把 Y 分类为 O9。核内度数必须重新计算，不能把 X 的五度点在 Y 中仍然当作五度点。
