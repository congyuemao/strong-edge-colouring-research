# 单点阻塞的八点组件刚性与唯一归属

日期：2026-10-09。根代理提出组件刚性；结构代理成稿后，根代理、上界代理已分别全文独审通过。

## 1. 阻塞点决定整个八点 B 分量

采用围长至少六、完整二因子冲突图及最优 `(4,4,2)` 分区。设坏 C 圈点 r 单独插入 B 后不能四色。

唯一高团五临界核是 O9，并使用 r 的全部五个 B 邻点。标号为高 K4 `r,b,c,d`，另两个 K4 为 `r,b,u,v`、`c,d,w,z`，低中心 x 邻接 u,v,w,z。

删去 r 后，b,c,d,w,z,x 六点在核内已经有四个 B 邻点，因 B 最大度四，全部旧 B 度恰四、没有核外 B 邻点。u,v 各已有三个核内 B 邻点。

如果 u 的旧 B 度为四，则 r 的饱和 B 邻点除了原来的 b,c,d，还包括 u；可是 u 不邻 c,d，这违反饱和邻点必须成团。v 同理。因此 u,v 的旧 B 度恰三，也没有核外 B 邻点。

所以这八点构成一个完整 B 连通分量 D。其图可写为五圈的簇吹胀：五个依次相邻的簇为

    {b}, {c,d}, {w,z}, {x}, {u,v},

每个双簇内部相邻，相邻簇间完全相连，其他簇间没有边。

## 2. 对同一个 D，阻塞补位至多两种类型

假设另一个坏 C 点 s 也由 D 阻塞。单点核同样使用 s 的五个 B 邻点，并由第 1 节决定整个 B 分量，所以其 O9 删根后的八点必须恰为 D。

D 中唯一的两点三度点是 u,v。补回任何 O9 高根时，这两点都须邻接新根，成为 O9 的两个四度低邻；另外三个邻点必须是在 D 中度四的高三角形。

在六个四度点 `{b,c,d,w,z,x}` 内，三角形只有 bcd、xwz，以及 K4 cdwz 内的四个三角形。后一类不能与新根组成 K4，否则和已有 cdwz 的 K4 共享三点，违反围长六的 K4 几何。

所以只有两个补位类型：

    N_B(r)={b,c,d,u,v},
    或 N_B(r)={x,w,z,u,v}.                            (1)

## 3. 同型和异型各自都禁止出现两个根

若两个不同根使用第一种类型，它们各与 b,c,d 构成 K4；这两个 K4 共享三点，不可能。第二种类型同理。因此每种类型至多有一个根。

若两种类型分别有根 r,s，则有五个 K4：

    rbcd, cdwz, wzxs, xsuv, uvrb.

相邻两个 K4 共享的两条红边，必为同一个完整红二星。于是 `{r,b},{c,d},{w,z},{x,s},{u,v}` 是五个两两不交的完整红二星；各原中心两两不同。五个 K4 分别给相邻星中心间的蓝边，组成原蓝五圈，违反围长至少六。

因此同一个 B 连通分量至多阻塞一个坏 C 顶点。这里无需先假定两个根来自不同 C 奇圈，结论比“每个分量只阻塞一个圈”更强。

## 4. 当前意义

坏 C 点到其阻塞 B 分量的映射是单射，每个像都是上述八点图。A、B 对称。

这使单点阻塞成为具有私有八点组件的结构，而非任意大部中的不明确障碍。但一个对某根私有的组件仍可能被其他圈的多个代表共同邻接；精确的统一颜色延拓条件见 `blocked_eight_uniform_extension.md`。本文没有把这种归属唯一性当成多点插入相互独立。
