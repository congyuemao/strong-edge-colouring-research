# 从全 B 阻塞奇圈同时取代表：联合最大度仍至多五

日期：2026-10-09。根代理、上界代理已全文独审第 1—7 节通过。它适用于任意数量的奇圈；进一步的全三度辐条同步四色见 `all_blocked_circles_list_extension.md`。

## 1. 背景

沿用围长至少六、四正则 G、完整二因子 F、冲突图 H 和两层最优 `(4,4,2)` 分区。称一个 C 奇圈为全 B 阻塞圈，如果其中每个点 v 都使 `H[B∪{v}]` 不可四色。

已有单点 O9 接口给每个这样的红边 v 一个满 B 端 α_v：此端的另一红边以及两处蓝邻点的四条红边全在 B，恰为 v 的五个 B 邻点。另一端 β_v 称为自由端。

`factor_girth_six_sync_interfaces.md` 第 4 节的投影引理说明：所有 B 阻塞根红边两两不共原端点，它们的 H 冲突恰来自自由端间的原边。因此一个全 B 阻塞 C 奇圈投影为同长度的原诱导奇圈，长度至少七。

## 2. 自由端投影圈事实上全是蓝边

把圈的根红边记为 v_i=α_iβ_i。设 a_i 是 β_i 处的另一红边。它不是 B：v_i 的五个 B 邻点已由满端用尽。它也不是 C：若是，它必须是 v_i 所在 C 圈的一个根，而该圈的 B 阻塞根彼此不共原端点。故 a_i∈A。

假设某条投影圈边是红边 `a_i=β_iβ_j`。由于 F 在 β_i 处只有 v_i、a_i 两条边，投影圈的另一条关联边必为蓝边；β_j 同理。

在 β_i 的两处蓝邻星中，沿投影圈那一处恰有一个 C 根和另一条 A 红边：另一条不能是 B，因为 v_i 的五个 B 邻点已满；不能是 C，因为 v_i 已有圈内两个 C 邻点。另一处蓝邻星的两条红边都同样必须是 A。故 β_i 一端给 a_i 至少三个 A 邻点；β_j 一端也给三个。

这六条 A 红边互异，因为它们属于根红边 a_i 的四个蓝邻红二星，无三、四圈保证四星八条红边互异。因此 a_i 在 A 中至少六度，违反 A 最大度四。

所以投影圈没有红边，全部为蓝边。每个自由端 β_i 的两条蓝边恰好用于该投影圈，没有第三条蓝边端口。

## 3. 每个根的五个 A 邻点

令 b_i 是满端 α_i 的 B 红伴边；沿 a_i 继续一步的红边记为 f_i，沿 b_i 继续一步的红边记为 g_i。

根 v_i 的两个 C 邻点就是 v_{i−1},v_{i+1}，分别位于自由端的两个蓝邻红二星中。五个 B 邻点已在满端一侧用尽。因此其另外五个邻点全部在 A，且恰为

    N_A(v_i)={a_i,a_{i−1},a_{i+1},f_i,g_i}.           (1)

特别 f_i、g_i 都属于 A。这五条边互异，来自完整十二邻点分解。

标准根邻域描述还给出：a_i 邻接 a_{i−1},a_{i+1},f_i，其他可能的 A 邻域内部边只有 g_i 到这三点的边。因此 `H[N_A(v_i)]` 是二部图，最大度至多三，不可能是 O9 阻塞根所需的两三角形共中心图。故每个全 B 阻塞圈点都可单独插入 A。

## 4. A 边能接触多少个这样的圈

考虑任意一批全 B 阻塞奇圈。将它们的所有 a_i 称为本批的 A 辐条。不同根的辐条不同：若同一红边连接两个不同自由端，则会成为投影红边；若两个根共享同一自由端，则违反根边匹配性质。

先看一条不属于这些辐条的 A 边 e。如果它冲突某根 v_i，则只能为 f_i 或 g_i。

理由是：e 不可能共享满端，因为那里另一红边 b_i 在 B；若共享自由端，就会是 a_i。若冲突见证是通向满端的蓝边，e 会属于满 B 星，矛盾；若为满端红伴边 b_i，就只能 e=g_i。若见证是通向自由端的蓝边，该蓝邻点只能是相邻自由端，e 必为相邻根的辐条，已被排除；剩余见证只能是自由端红伴边 a_i，给 e=f_i。

一条红边 e 在 F 中每个端点各只有一个红伴边。沿任一红伴边继续一步，最多到达一个根红边。因此不属于辐条的 A 边，至多邻接本批中的两个根。

再看一个辐条 a_i。它由于自身端点和自由端蓝圈，邻接本圈的三个根 `v_{i−1},v_i,v_{i+1}`。对于其余根，上一段端点分类只剩两步红延伸的可能。

a_i 不可能等于某个 g_j，因为其在自由端一侧的红伴边是 C 边 v_i，另一侧的红伴边 f_i 在 A；它没有作为 g_j 所需的 B 红伴边。若 a_i=f_j，则它的远端红伴边必须是另一个辐条 a_j；这一红伴边唯一。因此 a_i 除本圈外，至多还邻接另一个全 B 阻塞圈上的一个根。

所以：任何非辐条 A 边至多接触两个根；任何辐条 A 边至多接触两个不同的本批奇圈。

## 5. 任意数量代表同时插入后的度界

从这一批全 B 阻塞圈中，每圈任取一个代表，记集合 S。不同 C 分量没有 H 边，所以 S 独立。

第 4 节保证每个旧 A 度至多三的点，至多得到两个 S 邻点，因而在 `H[A∪S]` 中度至多五。旧 A 四度点本来就不可能同时接触两个不同坏 C 圈，所以也至多涨到五度。每个新增代表有五个 A 邻点，S 内又没有边，度恰五。

因此

    Δ(H[A∪S])≤5.

这个结论不要求各辐条旧 A 度恰为三，也不要求 S 的大小至多二。

若另有所有辐条旧 A 度三的附加条件，式 (1) 的三个显然 A 邻点已经用满各辐条的旧 A 度。因此辐条诱导图恰由每个原圈对应的一条 A 圈，加上若干远端红伴边关系构成的匹配组成；未配到另一辐条的 f_i 留在外部 A 中。这是进一步的结构限制，尚未用来完成联合四色。

## 6. 准确边界

### 6.1 四度辐条产生一个可插入 B 的旋转代表

若全 B 阻塞圈中某个 a_i 旧 A 度为四，则它与 v_i 零势交换，所得分区仍满足两层最优；否则已经降低奇圈数而与原最优矛盾。新的 C 圈代表为 a_i。

新分区中 a_i 的两个原红伴边分别是刚移入 A 的 v_i 与原本就在 A 的 f_i。因此 a_i 不可能有一个满 B 端，不能单点 B 阻塞；它可插入 B 后四色。

若还有另一个全 B 阻塞 C 奇圈，它保持原状：旧 A 四度点 a_i 不能接触两个坏圈。B 部没有改变，所以该圈仍全 B 阻塞；对新最优分区重新应用第 3 节，圈上任一点仍可插入 A。将它插 A、a_i 插 B，最终 C 恰为原 C 删除两个指定的原圈代表。

若另一个奇圈本来已有可插入 B 的点，则也可直接把该点插 B、原 v_i 插 A，无需旋转。因此只要还有另一个坏圈，这个四度辐条情形都给一个两圈修复。

### 6.2 所有辐条三度时的完整邻数

若 a_i 旧 A 度为三，则它已邻接 C 圈中的三个点 `v_{i−1},v_i,v_{i+1}`。任何邻接坏圈点的 A 顶点都满足 `d_B≥d_A+1`，故 d_B(a_i)≥4。

d_C(a_i)=3 也不可能。此时同时把不邻接的 `v_{i−1},v_{i+1}` 移入 A、把 a_i 移入 C，精确势变化为 `d_C(a_i)−3=0`。原奇圈删除两点后变成路径，新 C 中 a_i 只邻接 v_i，不能产生新圈；于是奇圈数下降，矛盾。

因此 d_C(a_i)≥4。总度十二迫其三部邻数恰为

    (3,5,4) 或 (3,4,5).

### 6.3 尚未解决的部分

一般多个坏 C 圈的代表同时插入 A，旧 A 三度点可能升到六度或更高。本文只在所选圈全部 B 阻塞时，用原红蓝端点结构排除了这种升度。

即使联合最大度五，仍可能含五临界核；本文没有把最大度五误作四色可染，也没有消除多奇圈同步问题。

## 7. 三度辐条的跨圈匹配端点再限制

若 a_i 的 profile 为 `(3,5,4)`，则它除了本圈三个 C 邻点外的第四个 C 邻点 x，不能位于另一个坏奇圈。

否则将两点 `v_{i−1},v_{i+1}` 和 x 同时移入 A，再将 a_i 移入 C。三点独立，每点均处坏圈且具有 `(5,5,2)` profile。按精确多点计数，势变化为

    3+[4−3+2]−2·3=0.

a_i 进入 C 后只剩一个 C 邻点，因此不能产生新圈；至少两个旧坏奇圈被切开，违反次级最优。

特别地，如果两条三度辐条 a_i、a_j 的远端红伴关系连接两个不同的全 B 阻塞圈，则二者 profile 都必须是 `(3,4,5)`。
