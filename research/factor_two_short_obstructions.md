# 两条充分路线的短反例

这两个例子都不是任意二因子十色的反例。它们分别否定“三重支配独立集”和一个更强的辅助四色引理，帮助限定后续换色论证的范围。附带程序只核验端点图和有限色表；下面的反证不依赖搜索结果。

## 1. 因子冲突图未必有三重支配独立集

取四层顶点 `(i,j)`，其中 `i` 模四、`j` 模五。红二因子 F 在每层形成五圈；前三对相邻层的蓝边为

    (i,j)(i+1,2j),          i=0,1,2,

最后一对蓝边为

    (3,j)(0,2j+1).

这是 `factor_c5_cycle_layers.md` 中 m=4、非零平移回绕的实例。它是二十点四正则简单图，围长至少五。层内红五圈无短圈；一个蓝匹配把五圈中的相邻点送到距离二的点，故跨一对层无四圈；跨四层的蓝四圈需要回绕映射有不动点，但回绕是 `j→j+1`，没有不动点。其他三、四圈投影不可能。

其红边冲突图 H 有二十点，十二正则。四个红圈分别给 H 中的 K5；相邻层之间的冲突是 K5,5 删去一份完美匹配；不相邻层之间没有冲突。

用红边中点坐标 `t=j+3`，相邻层唯一不冲突的边恰按对应蓝映射传播。因此一个独立集每层最多取一点；若有四点，则每层一点并必须沿四个非冲突匹配闭合，又会要求平移回绕有不动点。故 `α(H)≤3`。取前三层各自中点坐标零的红边，得到独立三集，所以

    α(H)=3.

若独立集 I 对每个外点至少有三个邻点，则双计 I 与其补集之间的边：

    3(20−|I|) ≤ 12|I|,

从而 `|I|≥4`，矛盾。因此不能通过一律寻找这种三重支配独立集来保证剩余最大度九。H 本身恰可七染，见原文件的独立上下界；这个障碍与十色反例不同。

## 2. 度五点形成团仍不保证四色

定义九点图 X。先取高团 `T={a,b,c,d}` 为 K4；其余点为 `u,v,w,z,x`。加边使

    {a,b,u,v} 和 {c,d,w,z}

分别形成 K4，再加 `xu,xv,xw,xz`。所以低图恰为共用 x 的两个三角 `xuv`、`xwz`。

四个高点的度都是五，其余五点的度都是四。X 的全部 K4 恰为

    abcd, abuv, cdwz.

它们任意两者最多共有两点，且 X 没有 K5。

然而 X 不可四色。因为 T 使用全部四色，u,v 被迫分别使用 c,d 的两色，w,z 被迫分别使用 a,b 的两色；于是 x 的四个邻点已经使用全部四色。给 x 第五色即可，所以 `χ(X)=5`。

因此下述辅助引理为假：最大度五、度五点全在一个团中、无 K5、没有两个 K4 共享三点，就能四色。附带程序还核验了删任意顶点后可四色，并保存九份色表；故 X 本身为五顶点临界图，而不仅仅包含某个未识别的临界核心。

## 3. 九点障碍确实具有围长六的原端点实现

先构造一个十四点部分原图。取四个红二星，中心分别为 B,E,G,H，每星有两片各不相同的新叶。分别把其两条红边标为

    B: a,b;    E: c,d;    G: u,v;    H: w,z.

另取红边 pq，标为 x。蓝边取

    BE, BG, EH, Gp, Hq.

其唯一圈是六圈 `B,E,H,q,p,G,B`。最大度不超过四，红度不超过二。由原边端点条件直接检查，这九条红边的冲突图恰为第 2 节的 X，没有附加冲突。

这还可以严格补成四正则、围长六且红边构成完整二因子的有限原图；不是只停留在一个不能补全的部分边集。

十四点部分图是二部图，每侧七点。对红、蓝分别将每个点的该色度补到二：两侧各有五个缺失红端口，以及九个缺失蓝端口。任意一一配对各色左右端口，形成五条新增红基边、九条新增蓝基边；此时允许基图有重边。

以群 `(Z/17Z)^2` 作纤维。旧基边的位移为 `(0,0)`；十四条新增基边分别赋不同标签 `t=1,...,14`，位移为 `(t,t²)`。每条边统一从左部指向右部，基边 uv、位移 s 的提升为

    (u,g)(v,g+s),       g∈(Z/17Z)^2.

提升图有 `14·17²=4046` 个点，红度和蓝度都恰为二，因而四正则且红边是二因子。不同新边标签不同且均非零，所以没有新旧边或新边之间的重边；原图二部性排除三圈。

若有四圈，其四条有向基边标签依次为 `t1,t2,t3,t4`，旧边标签记为零，则闭合条件给

    t1+t3=t2+t4,
    t1²+t3²=t2²+t4²       模17。

在奇素数域中，这迫使两侧无序对相同：先由和、平方和得到积相同，再将它们视为同一个二次方程的两根。因此标签多重集 `{t1,t3}` 与 `{t2,t4}` 相同。

如果标签均为零，则四圈完全由旧边提升而来，但旧图没有四圈。如果存在非零标签，该标签只对应唯一一条新增基边。在长度四的循环中，正位与负位相邻，所以这一相同标签的两次出现是沿同一提升边立即返回，不可能属于简单四圈。矛盾。

故提升图围长至少六；旧六圈仍留在每个单独纤维中，所以围长恰为六。每个纤维内部恰是原十四点部分图，因为所有新增位移非零。九条原红边的端点之间不会新增边，故其诱导冲突图仍恰为 X。

这说明不能仅凭“高点成团”和现有 K4 禁交几何排除 X。若要使用 `(4,4,2)` 分区，必须额外利用分区的全局最优性或允许多个点协同换部。

## 4. 可复现检查

运行 `factor_two_short_obstructions.py` 会从原端点重建两个冲突图，直接检查度数、短圈、独立集上界、九点图的所有 K4 和删除顶点色表，并构造上述 4046 点完整二因子实例后再次检查九点诱导冲突核心。结果保存在同名 JSON 中。
