# 十三点联合临界核的真实围长六二因子实现

日期：2026-10-09。本文件给出明确端点构造和可复现的有限证书。根代理已独立运行原验证器通过；upper_bound 代理另写 `joint_thirteen_realization_verify.py`，只读 JSON 从原端点重建并用独立深搜验证，全部通过。它说明较大的十三点五临界核确实能够出现在围长六原图的二因子冲突图中；它不构造一个满足全部最优分区条件的 A、B、C 分区。

## 1. 目标核

目标图 X 的点为 `p,q,a,b,c,U0,U1,U2,U3,V0,V1,V2,V3`。中心五点诱导 `K5−{pq,ab}`；U0..U3 和 V0..V3 各构成一个 K4；另加

    p—U0,U1;  q—U2,U3;
    a—V0,V1;  b—V2,V3.

没有其他边。

`joint_thirteen_obstruction.md` 独立证明它五临界。简单的非四色理由是：U 的 K4 迫 p、q 使用不同颜色，V 的 K4 迫 a、b 使用不同颜色；中心 p,a,q,b 的 C4 又包含所有交叉边，所以四点必须使用四种颜色，而 c 与四点都邻接。

删除 p,q 后最大度四；其饱和邻点集合 S_p、S_q 均为空，共同旧三度邻点 a,b 互不相邻。因而它并没有被两个代表的基本度数、饱和邻点成团和共同邻点三角形限制排除。

## 2. 二十点部分原图的纯端点描述

原顶点先取

    s,t,α,β,S,T,ξ,η,Z,Z',W,W',

再给 Z、Z'、W、W' 各取两个互不相同的新叶，共二十个点。

指定十三条红边为

    c=st, p=sα, a=tβ, b=Sξ, q=Tη,

以及 Z、Z'、W、W' 到其各自两个新叶的八条边。把 Z 的两条红边命名 U0,U1，Z' 的两条命名 U2,U3；W、W' 分别给 V0,V1 与 V2,V3。

蓝边恰为

    sS, tT, ξη,
    αZ, ZZ', Z'η,
    βW, WW', W'ξ.

每个原点度数至多四，红度至多二，蓝度也至多二。原图包含中央六圈

    s−t−T−η−ξ−S−s.

删去八个叶后，余图由这个六圈及两条补路径组成：从 s 到 η 的路径 `s−α−Z−Z'−η`，以及从 t 到 ξ 的路径 `t−β−W−W'−ξ`。每条补路径内部点互不重合，也不在六圈上；它们各长四，所接六圈上两端的最短距离为三，所以单用一条补路径形成的圈至少长七。若同时使用两条补路径，已含八条边。因此没有三、四、五圈，围长恰六。

直接按端点判断，十三条红边的全部冲突恰是第 1 节的 X：例如 p 通过 αZ 冲突 U0,U1，q 通过 ηZ' 冲突 U2,U3，而中间的蓝边 ZZ' 使四条 U 边互相冲突。V 同理。中心四圈 p−a−q−b−p 的冲突分别由原边 c、tT、ξη、sS 见证；c 又与它们四条都冲突。端点表中没有其他连接能增加核内冲突。

程序 `joint_thirteen_realization.py` 完全按原端点重新计算这些关系，并逐边验证，未导入目标核的生成器。

## 3. 完成到四正则原图及完整二因子

为消除“只是一份部分红图”的限制，程序还给出一个 2020 点的完整实现。

先在相同二十点上补七条红边、十一条蓝边，使红、蓝各成为简单二因子，且二者不重边。这个二十点基图不要求围长六。原来二十二条边保留为旧边，十八条新增边记录在 JSON 证书中。

取循环群 Z/101Z。每个基点 x 改为 101 个点 `(x,k)`；每条按编号定向的基边 x→y 赋电压 z，并提升为

    (x,k)—(y,k+z),  k∈Z/101Z.

所有旧边电压为零；新增边使用 JSON 中的十八个非零电压。每条红、蓝边都按其原色提升。因为基图简单且每个基边的提升是两个纤维之间的完美匹配，所得图简单四正则，红边和蓝边各为完整二因子。

有限检查枚举了基图的全部三、四、五圈，数量分别为 9、12、24。每圈沿定向取电压之和，要求在 Z/101Z 中不为零；其中不同线性式共 42 个，证书逐个通过。

这足以排除提升图的短圈：一个长度至多五的提升圈在简单基图中的投影是闭合且不回走的游走；若它重复某个基点，就分成两个长度至少三的闭游走，长度至少六。因此其投影必须是一个基图的三、四或五圈。非零电压使这种圈不可能提升为相同长度的闭圈。

旧中央六圈电压全零，所以提升图仍有六圈，围长恰六。程序又直接构造了全部 2020 点、4040 边，以原邻接表独立检查四正则、红二因子及围长六。

## 4. 十三点核在完成后仍然保留

取旧十三条红边在纤维零中的副本。旧边电压零，保证它们仍有同样的共享端点和旧连接；全部新增边电压非零，所以不会连接两个纤维零的旧端点。因此它们的诱导冲突图仍恰是 X。

程序对这个结论也直接重算了一次完整图中的端点冲突。JSON 记录 `induced_13_preserved=true`。

这是一份严格可验证的“较大联合核可在实际原图中出现”的证书，而不是十色反例。更不能据此断言某个最小势分区一定包含以 p,q 分属两奇圈的这种配置。

## 5. 此端点类型的两代表其实可分到不同大部

若在上述端点类型中，p,q 属于不同坏 C 奇圈、其余十一点属于 A，则 q 必可单独插入 B 四色。

若 q 不能插入 B，唯一单点 O9 核要求 q 的某个原端点处红伴边及两处蓝邻星全部在 B。q 的 T 端有蓝邻 t，而 t 关联两条 A 红边 c,a；q 的 η 端有蓝邻 ξ，而 ξ 关联 A 红边 b。两个端点均不可能承载这样的 B 核，矛盾。

所以这个实现虽排除了“实际联合核总是 O9”的过强猜想，却提供了一种可以修复的较大核。在两代表分别可插入 A 的前提下，可以将 p 插 A、q 插 B，同时切开两个原奇圈。

涵盖这个十三核全部端点类型的纯修复证明现见 `joint_common_path_repair.md`；本节仅给出当前端点证书自身最直接的修复理由。
