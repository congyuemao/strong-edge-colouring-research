# 围长至少七时 O9 禁形与双向单点插入

日期：2026-10-09。根代理提出路线，结构代理独立端点推导；根代理与上界代理均已完整独立审读最终文字通过。这只是同步问题的进一步接口。

## 1. 在围长至少六的原图中，任何 O9 都迫出原六圈

G 四正则、围长至少六，F 为完整二因子，H 为其冲突图。假设 H 含诱导 O9，标号采用 `joint_o9_all_pairs.md`：三个 K4 为 abcd、abuv、cdwz，低中心 x 邻接 u,v,w,z。

围长六的 K4 几何给出四个完整红二星 `{u,v},{a,b},{c,d},{w,z}`，其原中心 G0、B0、E0、H0 两两不同，并有蓝三边路径

    G0—B0—E0—H0.                                     (1)

**二星小引理。** 若一条别的红边 x 同时冲突完整红二星的两条边 `G0g1,G0g2`，则 x 的某个原端点与 G0 相邻。

x 本身不能关联 G0，否则原红度达到三。如果 x 的某端等于某个 gi，结论已经成立。否则，若没有端点邻接 G0，为了分别冲突两条星边，只能从 x 的端点向 g1、g2 各有一条连接。两条连接若使用同一 x 端点，就与两条星边组成四圈；若使用两个不同端点，就再加红边 x 组成五圈，均违反围长条件。引理得证。

应用于 G0 与 H0 的红二星，x 必有端点邻接 G0，也有端点邻接 H0。如果两次都使用同一个端点 y，则有二边路径 `G0−y−H0`。y 不等于 B0 或 E0：否则与 (1) 直接形成三角形；它也不等于 G0、H0，因为 x 不可能关联已有完整红二星的中心。因此这条二边路径与 (1) 组成原五圈，矛盾。

所以必须使用 x 的两个不同端点 y,z，并得到三边路径

    G0—y—z—H0,                                     (2)

其中 yz 就是红边 x。

这条路径内部与 (1) 不交。若 y=E0 或 z=B0，新增的 G0E0 或 B0H0 会形成三角形。若 y=B0，则只要 z≠E0，蓝二边路径 B0−E0−H0 与 B0−z−H0 形成四圈；若 z=E0，则 x=B0E0，但该原边已为蓝边，不可能又是红边。z=E0 的其余情况对称。

因此 (1)、(2) 是内部不交的三边路径，它们的并恰是一个原六圈。

## 2. 围长至少七的局部结果

若 G 围长至少七，第 1 节排除 H 中所有诱导 O9。

在最优 `(4,4,2)` 分区 A、B、C 中，坏 C 奇圈上的任意点 v 单独插入 A 如果不能四色，就会由唯一高团五临界核分类产生 O9。因此每个这样的 v 都可单独插入 A；完全对称地也可单独插入 B。

所以围长至少七时，所有坏 C 圈上的所有点都具有两个单点插入选择。这里比“每圈至少存在某个可插位置”更强，但仍不等于多点同时插入。

一个直接整数推论是：如果这样的最优分区 C 至多有两个奇圈，那么 H 十色可染。没有奇圈时直接四加四加二；一个奇圈取一点插入 A；两个奇圈各取一点，分别插入 A、B。两个部独立四色，余下 C 全是路径和偶圈。

## 3. 邻域中跨远端图也消失

`factor_girth_six_neighbourhood.md` 的每一条跨远端边，都与根边两侧的固定五边树路组成一个原六圈。因此当围长至少七时，全部这些跨边不存在。

每个 H 顶点的诱导邻域于是精确为两个相邻 hub，各自连接一组 `2K2+孤点`，没有两组之间的边。该邻域恰三色可染，而且每个二连通块都是三角形或单边。

尤其任何邻域中都没有诱导四圈，所以 H 本身没有诱导四轮。`joint_thirteen_obstruction.md` 的十三点核含一个诱导四轮，因此在围长至少七时也被排除。

这种邻域形状和 O9 禁形是任意规模的严格结构限制。本文尚未证明它们足以同步三个或更多坏 C 奇圈，也未宣称一般围长七十色定理。
