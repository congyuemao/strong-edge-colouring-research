# 围长六分区：同时阻塞的邻点限制与同步端口

日期：2026-10-09。沿用 `factor_girth_six_ten.md` 已严格证明的最小势 `(4,4,2)` 分区。本文只增加局部接口，不解决多个 C 奇圈同时插入的问题。

设 G 四正则、围长至少六，F 为完整二因子，H 为 F 在完整 G 中的冲突图。分区 A,B,C 先最小化该文件中的势，再最小化 C 的奇圈分量数。对一个 C 奇圈上的点 v，称其 **A 阻塞**，若 `H[A∪{v}]` 不可四色；B 阻塞同理。

## 1. 同时阻塞点的两个邻点分别可以插入两个大部

**命题。** 如果 v 同时 A、B 阻塞，那么它在 C 奇圈中的两个邻点可以分别记为 w_A,w_B，使

    H[A∪{w_A}] 可四色，    H[B∪{w_B}] 可四色。

本命题已由根代理及 upper_bound 代理分别独立核验通过。

由唯一 O 核及原端点解释，v 的一端 s 处红伴边 a 在 A，s 的两个蓝邻点处四条红边也全在 A。这五条边恰占满 v 的五个 A 邻点。另一端 t 处相应五条边全在 B。余下两个 C 邻点恰为沿 a、b 继续走一步的红边，分别记为 w_A,w_B。

假设 w_A 也 A 阻塞。w_A 已有红伴边 a∈A。它的 A 阻塞 O 核必使用 a 所在的二星：否则它会在另一端使用一条 A 红伴边及四条 A 蓝邻星边，再加上已有 a，得到至少六个 A 邻点，违背任何坏 C 圈点都恰有五个 A 邻点。

所以 v 的 A 核迫 a 的一端的两个蓝邻星四条边全在 A，w_A 的 A 核又迫 a 的另一端的两个蓝邻星四条边全在 A。这八条红边互不相同；任何重复都会在原图中产生长度至多四的圈。于是 a 在 H[A] 中至少有八个邻点，与该部最大度四矛盾。

因此 w_A 不 A 阻塞，即它可以单独插入 A 后四色。w_B 的结论完全对称。

特别地，同一 C 奇圈中同时阻塞的点构成独立集。若奇圈长为 ℓ，那么至少 `(ℓ+1)/2` 个点可单独插入某一个大部。若该圈含一个同时阻塞点，它至少具有一个 A 可插入位置和一个 B 可插入位置。

这些位置能单独插入，不表示它们能和其他奇圈所选位置同时插入。

## 2. 一个旧四度点不能连接两个不同坏奇圈

这是零势交换的直接后果，可用于限制多点插入造成的旧顶点升度。

设 v 位于一个坏 C 奇圈 D，w∈A 邻接 v，且 `d_A(w)=4`。已证计数给

    (d_A(w),d_B(w),d_C(w))=(4,5,3).

交换 v,w 为零势。写 `N_C(w)={v,x,y}`。由于交换后仍是全局最小势分区，新的 C 最大度仍至多二，因此 x,y 在 C−v 内的度数都至多一。

旧 C 是路径与圈的并。删去 v 后，D−v 变为一条路径；其余旧奇圈和偶圈中的点仍保持度二，所以 x,y 不可能来自这些圈。为了不减少 C 奇圈数，加入 w 必须重新产生一个奇圈。这只有在 x,y 是 C−v 同一条路径的两个端点，且该路径点数为偶数时才会发生。

这条路径可以是 D−v，也可以是原 C 的另一个偶阶路径分量；不能误认为两点总是 v 在 D 中的两个旧邻点。但两点绝不来自另一个旧奇圈。因此 w 不能同时邻接两个不同坏 C 奇圈。

对 B 中旧部内四度点也成立。若从每个坏 C 奇圈最多选一个点插入 A，则任何旧 A 四度点最多因这些插入增加一度；B 对称。旧三度或更低度点仍可能连接多个不同坏奇圈，因此这一观察尚不足以控制全部新增高点。

## 3. 多点交换的精确计数

设 w∈A，旧 A 度为 d，它邻接 k 个分别来自不同坏 C 奇圈的点 `v1,...,vk`。这些点在 H 中两两不相邻，因为它们属于 H[C] 的不同分量。

将这 k 个点移入 A，再将 w 移入 C。每个 vi 单独移入 A 的势代价为一，且相互之间没有边，所以前一步共增加 k。第二步中 w 的 A 邻数变为 d+k，C 邻数变为 `d_C(w)−k`，故总变化为

    ΔPhi = d_C(w)−d−k+2.

此外，任何邻接一个坏 C 圈点的 A 顶点 w 都满足 `d_B(w)≥d_A(w)+1`。单移势先给 `d_B(w)≥d_A(w)`；若等号，先将 w 零势移到 B，再把其坏圈邻点 v 零势移到 A，即可减少 C 奇圈数，矛盾。

所以若一个旧 A 三度点邻接至少三个不同坏 C 奇圈，取 k=3 得

    ΔPhi=d_C(w)−4,       d_B(w)≥4.

`d_C(w)≤3` 会严格降势；`d_C(w)=4` 时势不变，而新 C 中 w 只有一个邻点，不会产生圈，三个旧奇圈都被切开，仍矛盾。因此 d_C(w)≥5。结合总度十二，唯一可能是

    (d_A(w),d_B(w),d_C(w))=(3,4,5).

这精确隔离了三度点因多个奇圈代表插入而升到至少六度的风险，但尚未排除它。作为另一个应用，旧四度点已有 `d_C=3`；若它邻接两个不同坏奇圈，取 d=4,k=2 会给 `ΔPhi=−1`，这也是第 2 节结论的一份更短直接证明。

## 4. 单部阻塞点的冲突投影到原图

令 T_A 为全部坏 C 奇圈中 A 阻塞的点。这些点仍视为原红边。对每条 e∈T_A，唯一 O 核给出一个端点 s(e)：它的红伴边及两个蓝邻点处四条红边全在 A，恰为 e 的五个 A 邻点。称 s(e) 为其满端，另一端 t(e) 为其自由端。满端唯一，因为 e 若两端都有 A 红伴边，其中一个已经在这五条边之外，会使 A 邻数至少六。

**命题。** 映射 `e→t(e)` 是单射，并把 H[T_A] 同构映到原图 G 在这些自由端上诱导的子图。因此，若 G 二部，则 H[T_A] 二部。B 阻塞点同理。

先排除两条 T_A 红边共用端点。如果共享点是其中一条的满端，该点的另一条红边就是 C 点，而应为 A 红伴边，矛盾。如果共享点是两条边的自由端，则每条红边都通过另一条红边，看见另一条边远端的 A 红伴边。这是自己满端处五个 A 邻点之外的又一个 A 邻点，矛盾。各项互异由原图无短圈保证。因此这些红边两两不共原端点，自由端映射尤其单射。

再考虑连接两条红边某两个端点的一条原边。若该连接是蓝边，且触及某个满端，它在该满端的蓝邻星中带来一条 C 红边，与该处四条边均属于 A 矛盾。

若连接是红边，且恰触及一个满端，那么它在另一条红边的自由端形成 A 红伴边；另一条红边自己的满端又有一个不同的 A 红伴边，仍超过它的五个 A 邻点。若连接同时触及两个满端，则它是两条红边共用的 A 伴边；两个满端各给它四个不同的 A 蓝邻星边，使它在 A 内有至少八个邻点，违背 A 最大度四。

所以任何导致两条 T_A 红边冲突的原连接只能是自由端之间的边。反过来自由端相连当然导致冲突，证明了所述诱导子图同构。

当 G 二部时，一个坏 C 奇圈不可能全属于 T_A，所以它至少有一个可单独插入 A 的点；对 B 也成立。这比“至少可插入两部中的某一部”更强。但两种插入选项仍不能未经证明地同时处理所有圈。

一般围长六的 G 可以有七圈；一个完全 A 阻塞的 C 奇圈只会被这条投影迫成原图的奇圈，并未由围长条件直接排除。因此不能把二部情形的结论无条件推广。

## 5. 尚待闭合的同步问题

以上可选位置可能触及同一个 A 或 B 连通分量。一个位置的单点四色延拓，也可能改变另一位置所需的颜色分配。现有证明尚不能推出所有坏 C 奇圈都可以选一点同时处理。

特别需要继续控制旧部内三度或更低度点的多重升度，以及多个单点 O 核或其他临界结构在同一大部中的相互作用。本文不把局部候选数量、单点可插入性或零势转移数量误当作已经获得十色。
