# 五临界、独立高点路线：一个可闭合特例

本文研究新的中间命题：最大度五、五度点互不相邻、没有两个 K4 共享三点的 K5-free 图，是否一定四染。一般情形尚未证明，也没有反例。本文件证明一个任意规模特例，并明确尚缺的部分。

## 1. 单个高点的奇偶引理

若图 X 不含 K5，除一个指定点 v 的度至多五外，其余点度至多四，则 X 四染。

否则取顶点极小的非四可染诱导子图 Y。它连通，最小度至少四。若所有点度至多四，最大度四的完全图例外以外可以四染：其证明与 `factor_k12_cover_classification.md` 第5节的最大度五构造逐字相同，只把上界换成四（低度根、割点拼合、二连通图的两个不邻邻点同色）。唯一完全图例外 K5 已排除。

因此 Y 必含 v 且 d_Y(v)=5；其余点度全部为四。度数总和为 `4|Y|+1`，是奇数，矛盾。

这里的“只有一个高点”不能不经论证推广成多个独立高点。

## 2. 一个加权超图着色引理

设有限超图每条超边至少含两个不同顶点，且每个关联对 `(e,v)` 有正整数权 m(e,v)。假设

    Σ_{v∈e} m(e,v) ≥ 4       对每条超边 e，
    Σ_{e∋v} m(e,v) ≤ 5       对每个顶点 v。

则可以用四色给顶点着色，使每条超边都不是单色。

**证明。** 反设不成立，取顶点极小的反例；删除顶点时也删除包含它的全部超边，不缩小超边。每点至少属于四条超边，否则先染删去该点的超图，再补回：每条关联超边至多禁止一种颜色。

于是每个关联权均至多二，否则某点的总关联权至少为 `3+1+1+1=6`。下面从每条超边选两个不同顶点，要求每个顶点被选至多三次。

建立一个整数容量网络：源点到每条超边的容量为二；每条超边到它包含的每个顶点的容量为一；顶点到汇点的容量为三。对任意超边子集 E′，令 d(v) 为其中包含 v 的超边数，w(v) 为这些关联的总权。由于各权至多二、总权至多五，有

    min(3,d(v)) ≥ w(v)/2。

因此

    Σ_v min(3,d(v)) ≥ (1/2)Σ_{e∈E′}Σ_{v∈e}m(e,v) ≥ 2|E′|。

这个不等式保证网络能把每条超边的两单位都送到汇点。为自证该接口：从零整数流开始沿增广路逐次增广；若未达到总需求而已无增广路，取剩余网络中源点可达点集，得到一个容量小于总需求的割。固定割中源点一侧的超边集 E′ 后，逐个顶点选择在割的哪边，最小剩余割容量恰为 `Σ_v min(3,d(v))`；这与上式矛盾。容量都是整数，得到的选择因此也是整数，且超边到顶点容量一保证每条超边选出不同的两个点。

把每条超边所选的两个顶点连起来；重复边只保留一条。所得简单辅助图最大度至多三，普通贪心四染即可。每条超边包含一对异色点，因此都不是单色，矛盾。证毕。

此引理不使用概率方法或外部着色定理。

## 3. 低图为 K4 桥树时可以四染

设 X 最大度至多五，T 是一个独立集，T 中点度至多五；其余点度恰为四。假设 X−T 的每个连通分量由若干互不相交的 K4，以桥连接成树，不包含其他顶点或其他块。并假设 X 不含 K5。

则 X 可以四染。这里不要求另行禁止两个 K4 共享三点。

先看一个低图分量 C，其中有 r 个 K4。每个 K4 顶点已经有三条块内边，因低点总度为四，它的第四条边只能是桥或通向 T 的一条边。不同桥因此在每个 K4 上使用不同端点。r−1 条桥共用去 `2(r−1)` 个端口，故 C 到 T 的边总数为

    4r−2(r−1)=2r+2 ≥ 4。

给 T 赋四种颜色后，C 可以延拓着色，当且仅当它在 T 中的邻点不是全同一种颜色。

下面给出这一接口的直接递归证明。以某个 K4 为根，沿桥树向上处理。一个非根 K4 在父桥处有一个指定接口点，其余三点各受一项约束：若连到 T，该点禁止其 T 邻点的颜色；若连到已经处理的子树，则子树或者可配合接口点的任意颜色，或者迫使子树端点为某个固定颜色 c，从而本点禁止 c。三个点每个要么没有禁色，要么各禁止一种颜色。

固定父接口点颜色 x 后，其余三点需从剩下三色中取不同颜色。唯一失败情形是三个点都禁止同一个颜色 c 且 x≠c；这是因为每个剩余列表至少有两色，三点的不同代表选择只有在三表同为同一二元集时失败。因此向父亲传递的允许色集合，要么是全部四色，要么是一个单色 c；后一种情形恰好要求三个子方向都传来同一禁色 c。

根 K4 的四点也各至多禁止一种颜色。四点不能取不同色的唯一情形，是全部四点禁止同一个颜色。递归回代，整个分量不能延拓，当且仅当所有通向 T 的端口都遇到同一颜色。这就证明了接口。

现在把每个低图分量 C 作为一条超边，其顶点集为 N_X(C)∩T，并令关联权 m(C,t) 为 t 到 C 的原边数。上述端口计算给每条超边总权至少四；T 点原度至多五，给每点总权至多五。

每条超边至少有两个不同顶点：若 r≥2，端口至少六，不能全接同一个度至多五的点；若 r=1，四个端口全接同一点会形成 K5，已排除。

由第2节，先四色染 T，使每条超边非单色；再由刚证的接口独立延拓所有低图分量。得到 X 的四色。

## 4. 为什么尚未解决一般独立高点命题

一般五临界图的四度点子图，即使已建立其块结构限制，也可能含有三角形、桥、奇圈等其他块，且低点可能邻接两个或更多高点。此时延拓条件不再只是“本分量的高邻点不可全同色”。

例如，一个低三角形的每点可以各有两个高邻点。若三点所见的高邻颜色对恰为同一个二元集，剩余两个颜色不足以染该三角；但这六个高邻并非全同色。因而不能直接套用第2节的非单色超边引理。

旧九点 K5 的 Ore 合成正含有这样的低三角：两个高点都连接整个三角，强制两个高点同色，再与另一低 K4 的非单色要求冲突。这也正产生两个共享三点的 K4。禁止该具体构形是否已经足以消除所有更复杂约束，仍待证明。

一个额外的构造障碍是：保持最大度五和高点独立的 Ore 合成，必须在边侧取两个没有高邻的四度点，在顶点侧取一个没有高邻的四度点，并按2+2拆分邻点；否则新合并点超度，或与旧高点相邻。首个九点 Ore 例的每个低点都已有高邻，因此不能继续这一构造并保持这些条件。这只排除一种反例制造途径，没有把一般五临界图分类成 Ore 图。
