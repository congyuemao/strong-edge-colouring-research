# 三个饱和私有邻点：完整二因子中的局部存活证书

研究日期：2026-10-09。无网络、论文或外部求解器。本文只用自写标准库 Python 完成目标构形、寻找分区并从原端点独立复核。

**结论范围。** `factor_five_clique_geometry.md` 第 17 节保留的三饱和形状，确能同时满足：完整四正则五围长原图、完整二因子、(4,3,3) 部内度限制、原分区的全部单点不降势、三个指定零势交换后再次全部单点不降势，以及交换前后唯一 A-K5 中每点的严格 (4,4,4) 邻数。本文给出一个 268 点完整证书。

但这个分区 **不是全局最小势**：另有明确的双点交换使势下降 2。因此没有证明三饱和能出现在真正全局最优、再最少 A-K5 的分区中，也没有排除它。

## 1. 规定的中央核与四个卫星

中央有八个原点 s_i,t_i，i∈Z4，边为

\[
q_i=s_it_i,\qquad s_it_{i+1},\qquad t_0t_2,\ t_1t_3.
\]

四条 q_i 及两条对角线 t0t2、t1t3 属于 F；其余四条中央连接不属于 F。

对每个 i，加入五个新点 a_i,b_i,c_i,d_i,e_i，四条 F 边

\[
a_ib_i,\ b_ic_i,\ c_id_i,\ d_ie_i,
\]

以及三条非 F 边 a_ie_i、s_ib_i、t_id_i。记四条卫星 F 边为 R_i。它们与 q_i 组成 (4,1) 型强五团。这个初始构形有 28 个原点，四个卫星支撑彼此分离。

每个 t_i 的原度已经是 4，且 F 度为 2；每个 s_i 仍缺一条 F 边。给它补入的第一条外边记 f_i，再沿其外端的另一条 F 边记 g_i。

初始分区锁定：

- q0 与全部十六条 R_i 边放 A；
- q1,q2,q3 放 B；
- 两条中央对角线放 C；
- f0,f2 放 B，f1,f3 放 C；四条 g_i 全放 C。

中央每个 q_i 的全部十二个冲突邻点已经由这一局部结构确定：其他三条 q、自己卫星 R_i 的四条边、两条对角线、f_i、f_(i−1)、g_i。因此 q0 的三部度为 (4,4,4)，q1,q2,q3 的三部度均为 (5,3,4)。这些等式在任何不增加短圈且保留既有边的完成中保持。

## 2. 完成与分区约束

程序 `factor_three_saturated_realization.py` 用固定种子 93017 完成原图：对原 28 点每个缺失的 F 或非 F 度槽，先连接到一个不同的新点，再在新点间分别补齐两个因子的度数。每加入一条边，直接检查是否制造三角形或四圈。采用 240 个新点，得到 268 点、536 边的简单四正则图；F 有 268 边。

这个完成阶段不判断势分区。分区阶段仅对这一个固定完整图做约束搜索，最初 108 点的较小外围试验未能满足完整局部约束，已另存记录，不作不可满足结论。

完整分区要求除上述锁定色外，所有固定 A 核均不与其他 A 边相接；同时要求：

1. 所有边的所有单点换部势增均非负。
2. 旧坏团 Q0={q0}∪R0 的每点度为 (4,4,4)。
3. R1、R2、R3 的每点旧度为 (3,5,4)，以保证 q0 与 qi 交换后新的坏团每点度为 (4,4,4)。
4. 对 i=1,2,3，执行 q0 与 qi 的零势交换后，全图再次满足所有单点换部势增非负。

这里的势为

\[
\Phi(A,B,C)=|E(H[A])|+|E(H[B])|+|E(H[C])|-4|A|-3|B|-3|C|.
\]

单点从部 c 移到部 b 的势增直接按

\[
d_b(v)-d_c(v)+r_c-r_b,\qquad (r_A,r_B,r_C)=(4,3,3)
\]

计算。搜索采用这些必要条件的违约代价，找到零违约分区后保存原始边表与完整颜色向量。它没有把搜索失败当成不可行证据，也没有把零违约当作全局最优。

## 3. 可复核证书

原数据保存在 `factor_three_saturated_realization_240_exchange.json`，含所有 268 个点的名称、两因子完整原边表、完整分区及规定的核心索引。

`factor_three_saturated_audit.py` **不导入生成器、搜索函数或原来的代价计算**，仅从此 JSON 的原端点重新建立图，再检验全部结论。已运行通过：

- G 简单四正则，无三角形、无四圈；F 每点度 2。
- F 的四个圈长度为 16、52、59、141，总计 268。特别地，F 本身没有五圈。
- 原端点重建的冲突图 H 十二正则。
- 分区大小 |A|=102、|B|=82、|C|=84，势为 −573。
- 唯一 A-K5 为红边索引 {0,10,12,13,14}；q0 的索引为 0。
- 三个 B 饱和私有邻点的索引为 2、4、6，各自三部度严格为 (5,3,4)，且它们在原 F 中是匹配。
- 所有单点换部都不降低势，各部最大内部度不超过 4、3、3。

三个交换的独立复核结果：

| 交换红边索引 | 交换后势 | 唯一 A-K5 的红边索引 | 全部单点不降势 |

| 0 与 6 | −573 | {6,28,30,31,32} | 通过 |

每个新坏五团的五个点均有 (4,4,4) 三部邻数。因而从中央四个强团的任意一个作为当前坏团出发，这个局部转移结构都通过了相应单点必要检查。

复现数学证书只需要运行独立审计器，无须再次执行启发式搜索。生成器亦保留；若把最终 JSON 作为可选的热启动参数，程序会重建同一个完整图并立即重新确认零违约分区。

## 4. 全局最优性被明确否定

独立审计同时穷尽所有两点换部，找到 37 个负势交换。一个具体例子是红边索引 77 与 131：

- 对应原边分别是 (56,118)、(86,160)；
- 原分区分别为 C、A；
- 交换两者的部标签，势由 −573 降为 −575。

这个下降直接按完整 H 的边数与部大小重算通过。它与核心三个零势交换是不同操作。

所以本例严格证明的是：**三饱和不能单靠完整二因子、局部端点预算、单点最优性和这三个零势转移后的单点最优性排除。** 本例没有满足全部全局最优势条件；继续排除三饱和时，仍可使用两点或多点同步交换、全局分量翻转及其他确由最优性产生的约束。
