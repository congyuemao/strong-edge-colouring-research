# (5,4,1) 分区：把奇圈同步改成匹配端点选择

日期：2026-10-09。根代理与结构代理分别独立推导单点接口；根代理已全文核验第 1—4 节，第 5 节已按其独审补上孤点余邻分支；修正版第 1—5 节已由上界代理全文独审通过。研究对象仍为四正则、围长至少六原图的完整二因子冲突图 H。因此 H 十二正则、无 K5。

## 1. 分区和坏边的精确邻数

把 H 的点分为 A、B、C，先最小化

    Φ=e(A)+e(B)+e(C)−5|A|−4|B|−|C|,

再最小化 e(C)。单点移部的常规比较给

    Δ(H[A])≤5,  Δ(H[B])≤4,  Δ(H[C])≤1.

例如若 A 内某点至少六度，不降势就要求它的 B 邻数至少五、C 邻数至少二，总度至少十三，矛盾；其余部同理。

C 因此由独立边和孤点组成。A 可五色，B 可四色：两个普通 Brooks 例外 K6、K5 均已由 H 无 K5 排除。若 C 没有边，再用一种颜色即可得到十色。

设 q 是 C 中一条边的端点。它的 C 度为一。移到 A 不降势给 d_A(q)≥5，移到 B 不降势给 d_B(q)≥4；两者和为十一。若 d_A(q)=5，零势移到 A 就减少一条 C 边，违反次级最优；若 d_B(q)=4 同理。因此

    (d_A(q),d_B(q),d_C(q))=(6,5,1).              (1)

## 2. 旧 A 五度邻点的零交换

设 w∈A 邻接某个坏 C 边端点 q，且 d_A(w)=5。

单移 w 到 B 给 d_B(w)≥4。若等于四，可先零势将 w 移到 B，再将已失去一个 A 邻点的 q 零势移到 A；后一移动切开其 C 边，矛盾。因此 d_B(w)≥5。

交换 q、w 的势差为

    ΔΦ=d_C(w)−2.

由势最优，d_C(w)≥2；总度十二随即迫使

    (d_A(w),d_B(w),d_C(w))=(5,5,2),

且交换为零势。

令 S_A(q) 为 q 的所有旧 A 五度邻点。任取 w∈S_A(q) 交换；任何另一个 t∈S_A(q) 都增加 A 邻点 q。若 t 不邻 w，就升为 A 六度，与零势后仍满足 A 最大度五矛盾。因此 S_A(q) 成团，且 `{q}∪S_A(q)` 是 H 的团，大小至多四。

## 3. 每个坏边端点都可单独插入 A

在 H[A∪{q}] 中，六度点恰为 q 与 S_A(q)，它们成团；其他点度至多五，且该图无 K5。

应用 `high_clique_low_clique_free.md` 的 k=5 情形，得到

    H[A∪{q}] 可五染。

这对每条坏 C 边的两个端点都成立。因而本路线不存在单点方向选择障碍：每个端点都可用 A 的五种颜色单独接收。

困难完全是从各坏 C 边中选一个端点以后，能否把这些端点一起加入 A 并五染。若能，B 四色、C 剩余一色，就给 H 十色。

## 4. 饱和旧点不能跨越两条坏边

仍取第 2 节的 w，其 C 邻点为 q、y。交换 q、w 后，新 C 中 w 与 y 相邻。若 y 属于另一条旧 C 边，它在交换后会有两个 C 邻点，违反全局最小势所保证的 C 最大度一。

所以 y 只能是 q 的原 C 伴点，或一个原 C 孤点。旧 A 五度点不可能接触两条不同坏 C 边。

因此无论每条坏边选择哪个端点，旧 A 五度点在联合插入后至多升为六度。但旧 A 四度或更低度点仍可能多次升度。

## 5. 端点选择具有平均负载界，但尚无整数选择证明

若旧 A 点 w 的 A 度为 a，且邻接至少一个坏 C 边端点，则

    d_B(w)≥a,   d_C(w)≤12−2a=2(6−a).           (2)

第一项证明：单移 A→B 给 d_B≥a−1；若等号成立，可零移 w 到 B，再将那个坏边端点零移到 A，从而切开 C 边，矛盾。a=0 时该下界本来就成立。

每条坏 C 边独立以相同概率选一个端点，则 w 平均得到的新增 A 邻点不超过 d_C(w)/2。因此联合 A 度的期望不超过六。

这只是分数/平均可行性，不能据此断言有一次选择让所有顶点的度都不超过六，更不能把最大度六直接当成五色保证。

旧 A 四度点的潜在超载更具体。它至多有四个 C 邻点；若它碰到三条不同坏边，则恰有四个 C 邻点，分布只能有两种：

1. 三条坏边上的数量分别为 `(2,1,1)`；
2. 三条坏边各贡献一个邻点，第四邻点是原 C 孤点。

证明：若从互异坏边取 r 个 w 的邻点一起移入 A，再将 w 移入 C，总势差为 `d_C−a+4−r`。在 a=4、d_C=3 的情形取三个邻点，势差为零，w 在新 C 中孤立且切开三条旧边，矛盾。d_C=4 但碰四条不同坏边时取四点，同样零势且减少坏边数。余下正是上述两种分布。第二种分布只移三个坏边邻点的势差为一，因此这一步不能排除它。

为了不让第一种四度点升为七度，须避免同时选择两个单例邻点；这形成一个二元禁选子句。第二种须避免三个坏边邻点全被选择，形成三元禁选子句。不同四度点的子句未证明总可同时满足；三度和更低度旧点还有更高元的容量约束。因此本稿只把同步问题改写成匹配的二选一选择问题，尚未解决它。
