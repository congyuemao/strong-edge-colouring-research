# 连通团覆盖临界图的规模界：独立匹配证明

本文件从基本匹配交换和团划分出发，不调用外部结构定理。它提供一个任意规模的临界图工具；没有证明20色总命题。

对图J，令θ(J)为把顶点划分成团所需的最少团数，并令σ(J)=|V(J)|−θ(J)。也可以将σ看成互不相交的团带来的最大节省：每个k点团节省k−1，未选顶点单独放置。

称J为团覆盖顶点临界图，若对每个顶点v都有θ(J−v)=θ(J)−1。等价地，σ(J−v)=σ(J)。

**主定理。** 若J连通且团覆盖顶点临界，则

|V(J)|≤2σ(J)+1，等价于 |V(J)|≥2θ(J)−1。

事实上，选择单点团最少的最优团划分后：若它没有单点团，则|V(J)|≤2σ(J)；若有单点团，则J为因子临界图，且σ(J)=(|V(J)|−1)/2。

## 1. 自证一个最大匹配分解

以下引理中的因子临界指删去任意一个顶点后都有完美匹配；单点也满足这个定义。

**匹配引理。** 对任意图R和最大匹配M，存在分割V(R)=D⊔A⊔C，满足：

1. R[D]的每个连通分量D_i都是奇数阶因子临界图。
2. A恰为D在外部的邻点集；因此D与C之间无边，不同D_i之间无边。
3. M在C上为完美匹配。每个A点由M匹配到某个D_i，且不同A点对应不同D_i。每个D_i内部，M恰匹配除一个点外的所有点；该剩余点或者匹配到A，或者未匹配。
4. D中的任意点都可被R的某个最大匹配暴露；而A∪C中的点不能被最大匹配暴露。

以下给出构造证明，不预设这个分解存在。

### 1.1 奇块内部的交替路

若奇块S因子临界，M在S内部匹配除基点b外的所有点，则对任意x∈S存在一条从b到x、长度为偶数、先用非M边后用M边交替的简单路。取S−x的完美匹配N，与M在S内取对称差：b和x是仅有的两个可能路径端点，因此它们处于同一偶交替路的两端。x=b时取空路。

### 1.2 交替森林的状态

维护一片森林，其节点有两类：

* 外节点：彼此不交的奇块，每块因子临界，且M在块内匹配除基点外的全部点；
* 内节点：单个顶点，它的M配偶是它唯一外节点孩子的基点。

根是外节点，其基点未被M匹配。非根外节点的基点由M匹配到其父内节点。外节点到内节点的森林边不属于M；内节点到外节点的森林边属于M。尚未入林的点称为未见点，它们按M成对。

初始时，每个M未匹配点各自组成一个单点根，其他点都未见。若M完美，则取D=A=∅、C=V(R)，引理立即成立。

对外节点内任意顶点x，从相应根的未匹配基点到x有偶交替路：沿森林行进，在每个外块内用1.1节从其基点走到下一条边的端点。森林上的块互不相交，因此所得路简单。交换该路后，得到一个同样大小的匹配，暴露x。

### 1.3 扩张及收缩

反复检查某个外节点中的点x向所在外节点之外的边xy。

* 若y未见，y有M配偶z，而且z也未见。把y设为内节点，把单点{z}设为其外节点孩子，并用xy把y接到x的外节点。所有不变量保持。
* 若y是内节点，不作处理。
* 若y属于另一外节点，且两外节点在不同树中，两条根到端点的偶交替路加上xy构成M增广路，违背M最大。因此这种情形不会发生。
* 若y属于同一棵树中的另一外节点，将这两个外节点在森林中的路径加上xy。它们的最近公共祖先必为外节点，因为每个内节点只有一个孩子。于是得到一个奇圈，其节点交替为外块和内点，另有一条连接两个外块的边xy。将这个奇圈上所有外块和内点合并为一个新的外块。

最后一步需检验新块因子临界。把旧外块暂视为奇圈上的单点。删去奇圈某节点后，剩余偶数长路径有完美匹配。若待删顶点位于某旧外块S，则在S内部匹配除该点外的所有点；将S节点从奇圈删去，并按该偶路径的完美匹配连接其余节点。其余每个旧外块只使用一条圈连接边，再在块内匹配除其连接端点外的全部点。若待删的是一个内点，直接删去该奇圈节点，再作相同构造。故新块因子临界。

M在新块内仍匹配除旧最近公共祖先外块的基点以外所有点：圈上各内点都匹配到其相应孩子外块，只有祖先外块的基点没有这样的内部配偶。新块的基点和父边沿用该祖先的；圈外孩子照常附接到合并后的节点。因此森林结构和全部不变量保持。圈内被合并的内节点随后也作为外块顶点重新检查邻边。

扩张会减少未见点；收缩会减少森林节点数。每次收缩至少减少两个节点，而总共至多有|V(R)|个点通过扩张进入森林。因此过程有限结束。

### 1.4 终止后的分解

令D为所有外块的并，A为所有内点，C为所有未见点。终止时外块之间没有边，否则会收缩或产生增广路；外块到未见点也没有边，否则会扩张。每个内点都有父外块，所以A恰为D的外邻点集。每个外块连通，故它们恰是R[D]的连通分量。

M的结构正是引理第3条。若外块数为q，内点数为a，那么森林根数为q−a；这也是M未匹配点数。每个D点可被某个同样大小的匹配暴露，已由1.2节证明。

最后，任意匹配最多通过A与q个奇块中的a个块相连。每个没有向A使用匹配边的奇块，至少留下一个未匹配点。因此任意匹配至少在D中暴露q−a个点。最大匹配总共只暴露q−a个点，故不能在A或C暴露点。也因此，在任意最大匹配中，所有A点都匹配到彼此不同的D块，各D块至多一个点匹配到A；否则可被外部匹配的奇块数少于a，暴露点总数会超过q−a。匹配引理证毕。

## 2. 从最优团划分导出匹配结构

选取J的一个最优团划分P，并要求其中单点团数最少。令B为P中大小至少3的那些团的全部顶点；令R=J−B。

P在R上的二点团组成一个匹配M，其余点为单点。M必为R的最大匹配；否则换成更大匹配会增加σ(J)。

若P没有单点团，每个团至少有2点，所以n≥2θ(J)，等价于n≤2σ(J)，结论已得。以下假设P有单点团，因而M有暴露点。对R应用第1节匹配引理，得到D,A,C和因子临界分量D_i。此时D非空。

### 2.1 D与B之间没有边

反设d∈D邻接b∈B，b所在的大团记Q。换用一个暴露d的最大匹配，在R上仍使用同样多的二点团和单点团。然后将团Q及单点{d}换成两个团Q\{b}和{b,d}。因为|Q|≥3，这两个新团都至少2点。

团总数未变，但单点团少了一个，与P的选择矛盾。因此D到B无边。结合D到C无边，D的外邻点恰为A。

### 2.2 每个奇块的最大节省恰等于近完美匹配数

写|D_i|=2t_i+1。因子临界性给σ(D_i)≥t_i。

若σ(D_i)>t_i，选一个暴露D_i中某点的R最大匹配。由1.4节的等号结构，这个D_i没有匹配边通向A，其内部使用恰t_i条匹配边。把这t_i个二点团和单点替换为D_i上节省更大的团划分，保持其他团不动，就会增大σ(J)，矛盾。

所以σ(D_i)=t_i。

### 2.3 A必须为空

令W=B∪C，考虑诱导子图J[W]。原划分P在W上的大团和C的匹配边必须达到σ(J[W])，否则可直接替换它们增加全局节省。

M在每个D_i内部贡献t_i，在A到D的匹配边上贡献|A|。故

σ(J)=Σ_i t_i+|A|+σ(J[W])。

另一方面，删去任何顶点集合S，每删一个顶点至多损失一份团节省，所以一般有σ(X)≤|S|+σ(X−S)。假设a∈A，应用于X=J−a、S=A\{a}。由于删A后各D_i与W彼此分离，得到

σ(J−a)≤|A|−1+Σ_iσ(D_i)+σ(J[W])=σ(J)−1。

这与团覆盖顶点临界要求σ(J−a)=σ(J)矛盾。因此A=∅。

## 3. 连通性结束证明

A为空时，每个D_i与图中其他所有点之间均无边。D非空而J连通，所以只能有一个D_i，且它等于V(J)。于是J因子临界，且由2.2节

n=2t_i+1=2σ(J)+1。

主定理证毕。

## 4. 对当前强边染色研究的含义

若H是任意21色顶点临界冲突图，J为其补图，则θ(J)=χ(H)=21，且J团覆盖顶点临界。若J连通，主定理迫使|V(H)|≥41。

若J不连通，每个分量分别团覆盖顶点临界。设J有c个分量，总顶点数n，则对各分量求和得n≤2σ(J)+c=2(n−21)+c，即c≥42−n。

这些结论适用于有三角形的补图；不像之前只对无三角补图使用匹配数的推导。

再利用冲突图最大度24，补图J最小度至少n−25。对任意分量J_i，记其阶数n_i、最小度δ_i。其补图的贪心染色给θ(J_i)≤n_i−δ_i，所以σ(J_i)≥δ_i≥n−25。因此当n>25时，

c≤(n−21)/(n−25)。

与c≥42−n结合，得

(42−n)(n−25)≤n−21，即 n²−66n+1029≥0。

26≤n≤40的每个整数均违反此式。因此这一整段规模对任意补图都排除，不再需要无三角假设。结合critical25.md及根代理之前对更小规模的证明，任意21临界冲突边集F至少具有41条边。

主证明已经由根代理及structural代理分别逐步独立核验。41点有三角补图的后续单独见critical41_triangles.md；本文件自身的推论不排除n≥41，更不构成20色全局证明。
