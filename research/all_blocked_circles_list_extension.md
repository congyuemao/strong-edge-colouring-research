# 全三度辐条的任意多圈同步四色延拓

日期：2026-10-09。结构代理提出；根代理、上界代理已全文独立审读第 1—3 节，并分别核验第 4—5 节正规化论证通过。统一第三层目标进一步见 `blocking_event_normalization.md`。

## 1. 一个圈加匹配的列表引理

令 L 是若干两两不交、长度至少五的圈，加上一个匹配 M 所成的简单图。M 的边可以连接不同圈，也可以连接同一圈的两个点；它不与圈边重合。每个圈指定一个中心点 z。

对每个顶点 x，定义两个 0/1 指示量：

- P(x)=1 当且仅当 x 是其所在圈的中心 z 或 z 的两个圈邻点之一；
- Q(x)=1 当且仅当 x 的 M 伴点是某个圈的指定中心。

若每个点 x 的颜色列表满足

    |L_x| ≥ d_L(x)+1−P(x)−Q(x),                    (1)

则图 L 可以从这些列表适当染色。

证明采用可复现的贪心剥离。反复删除当前剩余度数严格小于该点原列表长度的点。若全部删空，按删除次序的反向依次染色即可。

假设过程停在非空顶点集 K。对 x∈K，停机条件和 (1) 给出

    d_L(x)−d_{L[K]}(x) ≤ P(x)+Q(x)−1.             (2)

左边就是 x 向 K 外的 L 边数。因此：

- K 中每点至少满足 P=1 或 Q=1；
- 若 P+Q=1，则它的全部 L 邻点都在 K；
- 若它有一条圈边通向 K 外，则 P=Q=1，且其 M 伴点仍在 K，因为这一条圈边已经用完 (2) 允许的唯一外向边。

固定一个原圈。K 在该圈内若非空且非整圈，每个连续段的两个端点都有一条圈边出 K，故两个端点都位于中心及其两个邻点组成的三个连续位置内。单点段不可能，因为它有两条圈边出 K；两个以上的段也不可能，因为需要至少四个不同端点，而 P=1 的位置只有三个。

所以 K 在一个圈上只有以下四种可能：

1. 空集；
2. 含中心的一个二点或三点短段；
3. 整圈；
4. 除中心外的全部顶点，即一个长段。

上述枚举只用了三个连续 P 位置：短段端点可以是相邻的两个 P 点，也可以是两侧 P 点；两侧 P 点之间沿另一方向的长段恰好漏掉中心。

下面选出一些必须经 M 匹配到 K 内指定中心的顶点。

- 每个短段的两个端点满足 Q=1，且其 M 伴点在 K；
- 每个整圈中至少 `ℓ−3≥2` 个 P=0 的点必须 Q=1，且由 (2) 没有外向边，故 M 伴点在 K；
- 每个长段的两个端点，以及其余 `ℓ−3` 个 P=0 的点，都必须经 M 连到 K 内指定中心，共 `ℓ−1≥4` 个。

设短段、整圈、长段的数量分别为 s,f,t。所选顶点数至少 `2s+2f+4t`。这些顶点的 M 伴点是互不相同的 K 内指定中心，因为 M 是匹配。但 K 内指定中心只来自短段和整圈，总数恰为 s+f。因此

    2s+2f+4t ≤ s+f,

非空 K 使 s+f+t>0，矛盾。引理成立。

本引理实际上对长度至少五成立；本研究的应用中圈长至少七，相应计数还可加强为 `2s+4f+6t≤s+f`。证明不要求所有指定中心独立，也不要求 M 只连接不同圈。

## 2. 应用于全 B 阻塞奇圈

使用 `all_blocked_circles_joint_degree.md` 的记号和已证明结构。取任意多个全 B 阻塞的 C 奇圈，并额外假设这些圈的每条 A 辐条 a_i 旧 A 度都是三。

所有辐条组成的集合记为 W。原证明给出：

- 不同圈的辐条不重合；
- 每圈的辐条形成同长度的圈，长度至少七；
- 每条辐条 a_i 的三个 A 邻点恰为 `a_{i−1},a_{i+1},f_i`；
- 若 f_i 也是本批辐条，则 a_i 与 f_i 是远端红伴边。这些关系组成匹配 M；若 f_i 不在 W，则它是 a_i 唯一的外部 A 邻点。

因此 `H[W]` 正是第 1 节中的圈加匹配图。每圈任取一个原 C 代表 v_i，对应的辐条 a_i 为该圈指定中心。令所有代表构成 S。

先给 `H[A\W]` 四色：它是已知可四色的 H[A] 的诱导子图，故可直接限制任一旧 A 四色。不同 C 圈之间没有 H 边，所以 S 独立。

代表 v_i 的五个 A 邻点是

    a_i, a_{i−1}, a_{i+1}, f_i, g_i.

前三点都在 W，g_i 不在 W，f_i 可在 W 或外部。因此每个代表至多看到两个已染外部邻点，可以任取一个未被它们使用的颜色先染。各代表之间互不干扰。

现在恢复 W。设 x∈W，其 M 度为 m(x)∈{0,1}，则

    d_{H[W]}(x)=2+m(x),

且它在旧 A 外部已有 `1−m(x)` 个邻点。它与先染代表的邻接恰分为两类：本圈三个连续位置给 P(x)，以及 M 伴点恰为指定中心时给 Q(x)。没有其他代表邻接。

故在四种颜色中，x 的剩余列表至少为

    4−(1−m(x))−P(x)−Q(x)
      =d_{H[W]}(x)+1−P(x)−Q(x).

即使两位代表使用不同颜色，这个下界仍成立；若同色，只会留下更多可用颜色。第 1 节遂给 W 的列表染色，完成整个 `H[A∪S]` 的四色。

因此得到纯任意规模结论：

> 从任意多个全 B 阻塞 C 奇圈中每圈任取一个代表，只要这些圈的所有 A 辐条旧 A 度都是三，这些代表就可以同时加入 A 后四色。

所有这些 C 奇圈可以同时切开，B 保持原四色。若它们就是全部坏 C 圈，则 C 剩余可二色，于是整个 H 用 `4+4+2=10` 色。

## 3. 边界与构造性

这里只使用圈加匹配的纯列表引理；没有假定单点可插入就自动保证多点可插入，也没有把联合最大度五当作四色保证。

对于未经额外规范化的分区，辐条中存在旧 A 四度点时，它可能有额外的 A 邻边，上述列表预算会变差，圈加单匹配模型亦不再充分。第 4—5 节通过第三层最优消除全阻塞圈中的这类四度辐条；其他类型的坏 C 圈仍未全部处理。

算法由一次外部四色、独立代表选色、线性规模的剥离和逆序列表贪心组成。外部四色可以沿用已有 A 四色；本接口本身无需搜索颜色赋值。

## 4. 第三层最优消去整圈中的四度辐条

在原两层最优分区的集合中，进一步最小化“全 B 阻塞的 C 奇圈数量”。这个第三评价是有限非负整数，故这样的分区存在；原两层最优推出的全部性质仍然适用。

断言在这个分区中，每个全 B 阻塞圈的所有 A 辐条均为旧 A 三度。

否则取其中一条四度辐条 a_i。已证其 profile 为 `(4,5,3)`，而它已看见本圈三个 C 点 `v_{i−1},v_i,v_{i+1}`，故这就是它的完整 C 邻集。将 v_i 与 a_i 零势交换后，新 C 图恰好在原奇圈中以 a_i 替换 v_i；其余所有 C 圈与路径完全不变。特别奇圈数不变。

B 没有任何变化。新 C 点 a_i 的两个原红伴边是现属 A 的 v_i 和原本就在 A 的 f_i，因此它不具备单点 B 阻塞所必需的满 B 端，故它可单独加入 B 后四色。于是这个原全 B 阻塞圈变成一个包含 B 可插入点的圈。

其他 C 圈的顶点及 B 集合均未改变，所以它们各顶点的 B 可插入性完全不变，不会产生新的全 B 阻塞圈。第三评价严格下降，矛盾。

由此，第 2 节可以无附加假设地用于这个规范化分区中的全部全 B 阻塞圈：每圈任取一个代表，都能同时插入 A 后四色。这个结论使用第三层规范化，不声称任意原始两层最优分区都已经没有四度辐条。

仍然剩下那些本来就含有 B 可插入点的坏 C 圈。它们各自的单点 B 可插入性，不能直接拼成全部代表的联合 B 四色。因此第三层规范化加本文列表引理，尚未完成一般十色证明。

## 5. 对称第三势可同时规范化两个方向

在原两层最优分区中，最小化下列两项之和：

    全 A 阻塞 C 奇圈数 + 全 B 阻塞 C 奇圈数。     (2)

断言在这个分区中，全部全 B 阻塞圈的 A 辐条均三度，而且全部全 A 阻塞圈的 B 辐条均三度。

只需研究全 B 阻塞圈的 A 四度辐条 a_i，并证明第 4 节交换还不会增加另一个方向的计数。令

    T={a_{i−1},a_{i+1},f_i}.

T 是独立三点集。交换前 v_i 的 A 邻点为 `{a_i}∪T∪{g_i}`；交换后新 A 点 v_i 恰有四个 A 邻点 `T∪{g_i}`。因此它在新 A 内的邻域含有独立三点集 T。

若交换后的某个旧 C 圈点 w 新变成 A 阻塞，则它的整个阻塞 A 分量是已证明的八点图。这个八点图的六个四度点，各自的部内邻域或者是两个不交边 `2K2`，或者是一个三角形附接一个叶点的四点图；两种图的独立数都至多二。

所以新加入 A 的四度点 v_i 不可能属于该阻塞八点分量。对应的 O9 子图因此完全使用旧 A 顶点及 w，在旧 `H[A∪{w}]` 中原本就存在。于是 w 在交换前已经 A 阻塞：交换不能让任何保留下来的旧坏 C 圈点新变成 A 阻塞。

对于新 C 点 a_i，它同时可插入两部：

- 可插入 B，因为两个原红伴边 v_i、f_i 现都在 A，不可能有满 B 端；
- 可插入 A，因为新 `A′∪{a_i}` 与旧 `A∪{v_i}` 是同一顶点集，而旧 v_i 由整圈结构已知可插入 A。

交换在 C 中仅把 v_i 换成 a_i。该圈现在两类全阻塞都不是，其余圈的 B 阻塞情况完全不变，而 A 阻塞只可能减少。因此 (2) 严格下降，矛盾。

对称论证处理全 A 阻塞圈的 B 四度辐条。断言成立。

于是可把所有全 B 阻塞圈各选一代表，同时插入 A；又把所有全 A 阻塞圈各选一代表，同时插入 B。两批圈互不重合：全 B 阻塞圈的每点都 A 可插，不能又是全 A 阻塞圈。两次列表染色使用不同的大部，彼此独立。

这在任意规模上同时处理了两个方向的所有整圈单向阻塞。若规范化分区中每个坏 C 圈都属于这两类之一，则整个 H 得到十色。

准确剩余是那些既不全 A 阻塞、也不全 B 阻塞的 C 奇圈。每个这样的圈都至少有一个 A 可插点和一个 B 可插点，但这些点的联合插入仍未证明。本文不把它们的两个单点选项当成已经解决的全局同步。
