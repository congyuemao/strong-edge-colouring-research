# 十三点核的三个代表：三种轨道与零势归约

日期：2026-10-09。上界代理独立组合推导。此稿仅声称保持 `(4,4,2)` 的前两层最优，不声称保持阻塞事件、满端数量或已经选定的全批次分配。

## 1. 标号与独立三点集的完整分类

使用 `joint_thirteen_obstruction.md` 的十三点图：p,q,a,b,c 在中心诱导 `K5−{pq,ab}`，两个旧 K4 附件 U、V 按 `U_p/U_q`、`V_a/V_b` 分别接两对端点。每个二元组都有两个点。

假设三个不同坏 C 奇圈的代表恰为核内三个独立点，其余十点属于 A。

独立数恰为三，且独立三点集在核自同构下只有以下三类：

    I：  {p,q,v}，v∈V；
    II： {p,u,v}，u∈U_q，v∈V；
    III：{c,u,v}，u∈U，v∈V。

纯分类如下。U、V 内各至多选一点，中心五点的独立数为二。若选两个中心点，只能为 p,q 或 a,b；相应被选端点覆盖整个相应附件，第三点只能来自另一附件，得到 I。若只选一个中心点，高中心 p 的第三点只能来自与它不邻的 U_q，并另取 V 一点，得到 II；选择 c 则只能各从 U、V 取一点，得到 III。没有中心点时总共只能选两点。

这也给出全部独立三元组数量：I 类 8 组，II 类 32 组，III 类 16 组，共 56 组。数量只是分类的核对，不是证明所依赖的穷举。

## 2. I 类已经由搭档匹配捕获

对 I 类代表 p,q,v，两个高根的完整 A 邻域仍分别为

    P3(a,c,b)+K2(U_p)， P3(a,c,b)+K2(U_q)。

U 整个仍属于 A；另一个附件 V 中有第三个 C 代表不影响这两个等式。因此 `joint_thirteen_pair_matching.md` 的较强搭档关系仍包含边 pq。

所以使所有这种搭档边跨 A/B 两个接收部的分配，会自动排除 I 类十三点核。这不需要 V 全部属于旧 A。

## 3. II 类经一次零势交换归约到 I

规范代表为 p、u∈U_q、v∈V。q 属于旧 A；其四个核内 A 邻点是 a,b,c 以及 U_q 中除 u 外的一点。因此 q 旧 A 度已经恰为四，而且邻接坏 C 根 u。

已证接口给 u↔q 为零势交换；交换后仍是前两层最优。q 进入一个补回的坏 C 奇圈，其他两个原奇圈保持：旧 A 四度点 q 不可能接触两条不同的坏 C 奇圈。

核内新的三个 C 代表正为 p,q,v，属于 I 类。p 的完整 A 邻域未变，因为 p 与 u、q 都不邻；v 同样与 u、q 都不邻。核本身的诱导边始终没有改变。

这一步没有证明新 q 也无满端，也没有证明其他圈的满端统计保持。因而它是一个前两层最优状态间的零势归约，不是可以在已有全批次染色选择之后任意执行的操作。

## 4. III 类经两次零势交换归约到 I

通过独立交换 p/q、a/b 及附件内两点，可规范为

    {c,u,v}，u∈U_p，v∈V_a。

q 属于 A，其四个核内 A 邻点为 a,b 和 U_q 两点，故旧 A 度恰四，且邻接根 c。先零势交换 c,q；u、v 所在两个旧坏圈保持。新的代表集为 q,u,v，是 II 类。

也可直接核对下一步的度数。原 p 同时邻接 c 与 u 两个不同坏圈，因此不可能是旧 A 四度点。它的三个核内 A 邻点为 a,b 及 U_p 中另一点，所以旧 A 度恰三。第一步把其邻点 c 从 C 移入 A，而 p 不邻 q，因此 p 升为 A 四度。于是第二步可零势交换 u,p。

最后核内三个 C 代表为 p,q,v，归约到 I。第二步也不破坏 q、v 当前所在的其他坏圈，由同一个旧 A 四度点不能跨两坏圈的接口保证。

最终整个 C 可能在被触及的两处奇圈中作了顶点替换，也可能使用允许的旧偶阶路径来补回奇圈；不必预设每次都在原圈内换点。需要的只是每步仍为前两层最优，且另外指定的坏圈不受影响。

## 5. 尚缺的全局接口

三种轨道都能在前两层最优状态中归约到搭档匹配型，这比只列出三代表例外更具体。

但由此仍不能声称所有十三点核都被同一个代表分配排除。归约会改变 A 的点集与被选代表，可能改变其他搭档关系，以及第三、第四层的优化统计。要把这些旋转同时使用，需要另证选择或交换过程的全局终止性、兼容性，或直接处理三代表约束。
