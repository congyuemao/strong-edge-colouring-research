# 奇圈双点吹胀删一点：整个五临界族的两代表处理

日期：2026-10-09。根代理提出七圈核与旋转路线，上界代理独立验证并补全纯临界证明、完整旧度核查及整个奇圈族的范围。根代理已逐节独立核验本文纯证明通过。

## 1. 一个无限五临界族

令 N=2k+1≥3。把原圈每点换成两点团，相邻簇之间全部相连，再从簇 0 删除一个点。记所得图为 J_N。簇 0 是单点 z，其余簇都二点，编号模 N。

它有 4k+1 个点，独立集至多 k 点：每簇至多一个，所选簇在原奇圈上不相邻。因此 χ(J_N)≥5。

删除任意簇 j 的一个点后，剩余簇大小向量为 `2·1−e_0−e_j`（j=0 时簇 0 变空）。删去原奇圈点 0 后的偶阶路径，可以二染；两个颜色类是两个 k 点独立簇集。同样，删去原圈点 j 后得到另两个 k 点独立簇集。四个独立簇集的关联数正好为 `2·1−e_0−e_j`，所以可将剩余原图点分别放进这四个独立集，得到四色。

因此 J_N 逐删一点都可四色，且本身不可四色；给删点图四色、再给删除点第五色，知 χ(J_N)=5。整个族都是五临界。

N≥5 时最大度五。簇 0 单点以及簇 1、N−1 的四点度四；簇 2,…,N−2 的 `2N−6` 个点度五。

## 2. 两代表核只需处理 N≤7

一般两个不同坏 C 奇圈代表插入 A 后，联合图的五度点至多十个，见 `joint_o9_two_repair.md` 第 6 节。取临界诱导子图只会降低顶点度数，故其中五度点数同样至多十。

若该核是 J_N，则 `2N−6≤10`，即 N≤8。因此奇数 N 只有 3、5、7：

* J_3=K5，被围长六冲突图的团界排除；
* J_5 正是 O9，已有全部代表轨道修复；
* 剩下 J_7，即十三点、八个五度点的新核。

所以后续七圈核的证明完成这个无限族的处理，不是仅排若干测试规模。

## 3. 七圈核的合格代表位置

记各簇为 V_i，V_0={z}。高簇为 V_2,V_3,V_4,V_5。每个高点删除代表后都必须降到至多四度，因此它必须是代表或邻接某个代表。

两个代表不能包含 z：它不邻接任何高点，另一个代表不能覆盖全部四个高簇。若代表含一个低双簇，例如 V_1，则它只覆盖高簇 V_2；另一代表必须位于 V_4，才能覆盖 V_3,V_4,V_5。可是这个 V_4 代表的五个邻点全为高点，且都不邻接 V_1 代表，删除后都是四度，违反其饱和邻点至多三的条件。V_6 对称；两个低簇同样无法覆盖高点。

故两个代表都在高簇。独立性排除同簇与相邻簇，余下簇对只有

    {V_2,V_4}，{V_3,V_5}，{V_2,V_5}。

前两者镜像等价，每对双簇有四个带标号代表位置。程序 `joint_c7_blowup.py/.json` 独立检查全部十二对和十三份删点四色证书，与此纯分类一致。

下面总把这两个代表记为 p,q，所属旧 C 奇圈不同，其余十一核点都属于 A。

## 4. 距离二的代表都可插入 A

取 p∈V_2、q∈V_4，记同簇另一点为 p'、q'。共同邻点 V_3 的两点同时接触两个坏圈，所以旧 A 度至多三；它们的三个核内 A 邻点已经是本簇另点、p'、q'，故这就是完整旧 A 邻集。

p 的五个 A 邻点是 p'、V_1 两点、V_3 两点。若 p 单独插入 A 后失败，唯一 O9 核要求 p 为高点，另外三个高点只能是 p' 与 V_1；V_3 是 p 的低邻对。由 V_3 的完整邻集，O9 的低中心必为 q'。q' 的完整旧 A 邻集恰为 V_3∪V_5，因为核内已有四个 A 邻点。因此新 O9 的另一对低叶必为 V_5，继而强迫 V_1∪V_5 构成 K4。但这两个簇在核内不相邻，矛盾。

对 q 的论证相同：共同低对仍是 V_3，低中心必为 p'，另一对低叶必为 V_1，而另外两个高点在 V_5，仍强迫不存在的 V_1—V_5 边。

故 p、q 各自 A 可插。这里没有把 V_1 点的核内旧度三误作完整旧度三；它们允许有核外 A 邻点，证明仍然成立。

## 5. 距离三的代表都可插入 A

取 p∈V_2、q∈V_5，同簇另一点为 p'、q'。考察 q，其五个 A 邻点为 q'、V_4 两点、V_6 两点。

q' 与 V_4 两点在旧 A 内均已有四个核邻点，所以是三个饱和邻点。饱和邻点总数至多三，故 V_6 两点不能再为旧 A 四度；它们的完整旧 A 度恰为三，邻点分别是本簇另一点、q'、z。

若 q 插入 A 失败，新 O9 的三个其他高点必为 q' 与 V_4，低对为 V_6，低中心被其完整邻集迫为 z。另一方面，V_4 两高点插入后的完整核邻集迫其低对为 V_3，所以这个低中心 z 必须邻接 V_3。可是 z 的完整 A 邻集已经是 V_1∪V_6，恰四点，不含 V_3，矛盾。

故 q A 可插。镜像 i↦−i 把 p 与 q 交换，给出 p 也 A 可插。

## 6. 完整邻域真孪生旋转

选任意一代表 p 及其同簇伴点 p'。它们在原 F 中是同一个完整红二星：相邻双簇构成 K4，而两个这样的 K4 共享 p,p'；围长六的 K4 端点分类给出所述二星。

p' 在旧 A 的完整四邻集是 p 所属簇左右相邻的两个双簇；记此四点集为 X。p 的五个 A 邻点也恰为 `{p'}∪X`。因此交换 p,p' 是零势；另一个 q 奇圈不变。交换后的分区仍满足两层最优，并且 p' 成为补回的坏 C 奇圈代表。

把新 A 中的 p 重命名为旧 p'，两个完整诱导图

    H[A∪{q}] 与 H[((A−{p'})∪{p})∪{q}]

完全同构：p,p' 对其余所有 A 点的邻域都恰为 X，而且 q 不邻接这两个同簇点。于是第 4、5 节证明的 q A 可插性在旋转后仍成立。这是对整个 A 图的同构，不仅是对十三点核的同构。

原状态 p 与交换后的 p' 至少一个可插入 B。若两者都 B 阻塞，它们的共同红二星中心处都有另一条 A 边，故阻塞满端只能分别落在两个远端。第二条边远端的 B 伴边通过红伴边关系，给第一条边其满端五个 B 邻点之外的第六个 B 邻点，违反两者 B 邻数都是五。详细远端互异论证与 `joint_o9_all_pairs.md` 第 4 节相同。

选择当前代表可插 B 的状态，将它插 B、q 插 A。两个指定的原 C 奇圈同时切开，最后 C 恰为原 C−{p,q}。

## 7. 结论及准确边界

J_N 的整个奇圈双点吹胀删一点族，作为两代表临界核时已被高点界、原团界、O9 修复及上述七圈旋转覆盖。

这并未分类所有五临界图；修复后两个大部只知四色可染，不能未经证明继续套用原最优势处理其他奇圈。

七圈核还具有完整端点证书。结构代理的 `joint_c7_cover.py/.json` 从一个蓝七圈及每个圈点的两个红叶出发，在二十一点基图补全红、蓝两个二因子，再取模 101 的覆盖：旧边电压为零，新增边电压避开所有长度三至六的不回走闭步。所得原图有 2121 点、4242 条边，四正则且围长恰七，F 为完整二因子；纤维零中的十三条指定红边精确诱导 J_7。

上界代理另外编写 `joint_c7_cover_verify.py/.json`，只读证书重新构图，不调用生成器：直接深搜排除所有三至六简单圈，检查旧蓝七圈见证、原度四、红度二，并与 `joint_c7_blowup.json` 的独立抽象边表逐项比较。全部验证通过。该完整 G/F 证书不包含全局最优 A/B/C 分区；核的五临界性不等于无法进行这里的两部重分配。
