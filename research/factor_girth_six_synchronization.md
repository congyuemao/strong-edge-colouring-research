# 围长六路线的多奇圈同步接口

日期：2026-10-09。接续 `factor_girth_six_ten.md`。本文件只记录任意规模的严格必要条件与同步接口，没有解决全部奇圈的同时插入。

设 G 四正则、围长至少六，F 为完整二因子，H 为完整原图中的 F 冲突图。按前稿选择 `(4,4,2)` 全局最小势分区 A、B、C，并在最小势分区中使 C 的奇圈分量数最少。记这些奇圈的顶点并为 O。已知每个 v∈O 的三部度数为 `(5,5,2)`，A、B 均四色可染。

## 1. 每个 A-B 连通分量分别平衡

任取 H[A union B] 的一个连通分量 R，将 R 中 A、B 标签整体互换。A、B 的容量参数同为四，R 与其余 A-B 点没有 H 边，故 Phi 保持不变；C 完全不变，奇圈数也不变。

因此新分区仍满足全部最优性条件，每个 v∈O 在翻转后依然有 A、B 度各五。于是

    |N(v) intersect A intersect R|
      = |N(v) intersect B intersect R|.             (1)

这对每个分量 R 单独成立，不只是全部 A、B 邻点的总数平衡。

**双向可插入的充分条件。** 若某个 v∈O 的十个非 C 邻点分布在至少两个不同的 A-B 连通分量中，则 H[A+v] 和 H[B+v] 都可四色。

证明：假设插入 A 失败。前稿与高团分类给出九点 O 核，其中 v 为高点，并使用了 v 的全部五个 A 邻点。删去 v 后，这五个 A 邻点在核中仍连通，因此均在一个 A 分量、从而在一个 A-B 分量 R 中。式 (1) 迫 v 的五个 B 邻点也全部在 R 中，矛盾。B 的证明相同。

该结论不声称可插入点选择自动互不干扰；它只在跨 A-B 分量时提供两个目标部的自由度。

## 2. 一次同时删除多个奇圈的势不等式

设 u∈A，记 a=d_A(u)、b=d_B(u)、c=d_C(u)。假设 u 邻接 k≥2 个不同的 C 奇圈。则

    b >= a+1,
    c >= a+k-1,
    3a+k <= 12.                                    (2)

第一式：全局最小性给 b≥a。若 b=a，先把 u 零势移到 B，再取任一与 u 相邻的坏圈点 v，把 v 移到 A。v 的 A 邻数从五降为四，所以第二次移动也零势。C 只删除 v，不增加点，奇圈数下降，矛盾。

第二式：从这 k 个奇圈各选一个与 u 相邻的点 v1,...,vk。不同圈间没有 C 内边，所以它们彼此不相邻。一次把全部 vi 从 C 移到 A，并把 u 从 A 移到 C。

每个 vi 单独移动的势变化为一；u 单独移动的变化为 `c-a+2`；每条 uvi 在两次单移中都被误算为新同部边，而最终仍是跨部边，所以每条需减二。故总变化恰为

    Delta Phi = c-a+2-k.                            (3)

如果 (3) 为负，违反全局最小性。如果为零，新分区仍是全局最小势分区，因而 C 内最大度仍至多二。原来 k 个奇圈各被删除一个点，全部变成路径；唯一新增的 C 点 u 至多制造一个新的圈。因此 C 奇圈总数至少下降 k-1≥1，又违反次级最小性。故 (3) 至少为一，得到第二式。

最后由 `a+b+c=12` 与前两式即得第三式。B 部完全对称。

特别地：

* A 中原内部度四的点不能邻接两个不同的坏 C 奇圈。
* 原内部度三的点至多邻接三个坏 C 奇圈；若恰邻接三个，三部度数被迫为 `(3,4,5)`。

第一个推论不是说饱和点的所有 C 邻点都在同一个奇圈。它还可能邻接其他 C 路径的端点，见第 4 节。

## 3. 独立集合版本

若 S 是 `N_C(u) intersect O` 中的独立集合，并且 S 至少触及两个不同的 C 奇圈，则同样的同时移动计算给

    |S| <= c-a+1.                                  (4)

理由是每个选点单独移动仍花一，S 内无边，所以 (3) 中 k 可以换成 |S|。至少两个奇圈消失，而加 u 最多生成一个新圈，零势也不允许。

这个版本允许从同一奇圈选多个彼此不相邻的点，因此严格包含“每圈一个点”的计数。但不能把所有 C 邻点当成都在奇圈中，也不能省略至少触及两个原奇圈的条件。

## 4. 单个饱和点交换时的准确二分

设 v 在坏 C 奇圈 D 中，u∈A 邻接 v 且 d_A(u)=4。前稿已经证明 u 的三部度数为 `(4,5,3)`，交换 u、v 零势。

删除 v 后，D 变成一条路径 P，u 在新 C 中恰有两个邻点。为了不降低奇圈数，这两个邻点必须是 `C-v` 中同一条路径的两个端点，并且加 u 闭合出的圈为奇圈。否则无法产生新奇圈。

这条路径可以是 P，也可以是 C 中另一个原有路径分量。后者是实际允许的逻辑分支，不能误断言 u 的其他两个 C 邻点一定是 v 在 D 中的两个邻点。

它不可能使用另一个原奇圈的顶点：那个顶点原 C 度为二，也未因删除 v 降度，加 u 会使其 C 度达到三，违反新最小势分区的度界。这个事实与第 2 节“饱和点只触及一个坏圈”的推论一致。

## 5. 当前用途与缺口

这些引理控制多个奇圈对大部同一点的重复接触，并提供 A-B 分量翻转后的两目标自由度。它们尚未证明能为每个奇圈同时挑选一个点与一个目标部，使两个大部都保持四色。

特别地，即使每个单独插入都可行，也不能把这些插入直接并行；原 A 三度或更低的点仍可能被多个选点同时接触。上面的势不等式给出了这类相互作用必须满足的严格限制，而非将其预先排除。
