# 三饱和分支：恰一条中央对角线属于 F

日期：2026-10-09。自主纯数学推导，任意规模，允许四个卫星任意混合 `(4,1)` 与 `(3,1,1)`。完整证明已经根代理和反例代理分别独审通过。反例代理还独立得出不同末步：用 r2 见到 D0、f3 和 Z2 中的一个 C 点得到同一矛盾。

## 1. 沿用的接口

全部假设、最优性选择和中央核标号与 `three_saturated_cross.md` 第 1 节相同：

    qi=si ti,  ri=si t(i+1),  D0=t0 t2,  D1=t1 t3.

中央 qi 轮流作 A 点，其余三个作 B 点，四个状态都保持最小 Phi 与最少 A-K5。每个 Qi=qi+Ri 是坏 A-K5，卫星 Ri 固定为 A-K4。每个坏团点三部度数为 `(4,4,4)`；小部点如果对坏团有至少两个邻点，则本部度至多二。

本节假设 D0 属于 F 而 D1 不属于 F。中央高端 ti 的第二条 F 边选择迫使

    r0,r2 in F;   r1,r3 not in F.

## 2. 两种低端余边的统一定义

对偶数 i=0,2，si 的第二条 F 边是 ri。另两个原邻点均由非 F 边连接，其两处 F 星总共四条边，其中恰两条属于 Ri，另两条记为 Zi。它们均与 ri 冲突。正如 `three_saturated_cross.md` 第 3 节，(4,1) 时 Ri 两边来自同一 F 二星，(3,1,1) 时分别来自两星。

对奇数 i=1,3，si 的第二条 F 边记为 fi=si pi。它既非 qi，也非 ri；si 另有一个非中央的非 F 邻点 zi。令 gamma_i 是 pi 的另一条 F 边，考虑三条边

    gamma_i，以及 zi 的两条 F 边。

其中恰两条属于 Ri，余一条记为 ell_i。可按两种卫星核直接检查：

* `(4,1)` 时 fi 外伸到卫星支撑外，zi 是 Ri 路径的内部点；其两条 F 边都是 Ri，故 ell_i=gamma_i。
* `(3,1,1)` 时 si 的两个卫星邻点原本各关联一条 Ri 边，其中一个通过 fi 与 si 相连，另一个是 zi。gamma_i 是第一条 Ri 边；zi 的另一条 F 边即 ell_i。

因此 fi 总与 ell_i 冲突：第一型它们相交，第二型由原边 si zi 见证。同时 fi 与 qi 以及 Ri 的两条低端边冲突，所以在 qi 作中央 A 点的状态，fi 至少有三个坏 Qi 邻点。

## 3. 辅助中央三角的部别

D0、r0、r2 在 H 构成三角。D0 冲突所有四条中央 q，并经 t0、t2 的卫星连接看到四条固定 A 卫星边。因此它不在 A。若它在 B，三个中央 B 邻点使其 B 度饱和，而选 q0 或 q2 作 A 的状态时，它至少看到坏团三点，违背饱和外邻只能见一点的接口。故 D0 在 C。

r0、r2 均不在 A：例如 ri 与 qi 冲突，而在 qi 作 A 的状态，Ri 的四个 A 邻点已用满 qi 的 A 度。

它们至多一条在 B。假设均在 B，取 q2 作中央 A 点。r0 与其他三个中央 B 点冲突，还与 r2 冲突，于是 B 度至少四。

它们也不能都在 C。反设均在 C。对任一偶数 i，ri 与坏 Qi 的 qi 及低端两条 Ri 边冲突，故其 C 度至多二；D0 和另一条 r 已经占满这个预算。于是 Zi 两条都不能在 C。它们也不在 A，因为在 qi 作 A 的状态 Ri 已经给出四个 A 邻点。所以 Zi 两条全在 B。

但 qi 作 A 时，其另外三个中央 q 都在 B，B 度仅剩一个位置，不可能再容纳 Zi 的两个 B 点，矛盾。

所以 r0、r2 恰一条在 B、另一条在 C。循环重标两位后，可以设

    r0 in B,  r2 in C.                               (1)

## 4. 奇数低端的饱和矛盾

围绕 q3 精确列出十二个 H 邻点：

    N_H(q3) = {q0,q1,q2} disjoint-union R3
              disjoint-union {D0,r0,r2,f3,ell3}.      (2)

可逐原邻点核验：在 s3 处的 F 延伸为 f3，其后继以及另一非 F 邻点的 F 星给出 R3 的两条边和 ell3；经非 F 边 s3 t0 看到 q0、D0。在 t3 处的 F 延伸 r2 给出 q2；经非 F 对角线 t3 t1 看到 q1、r0；另一卫星连接给出 R3 余下两条边。整理为 (2)，共 `3+4+5=12` 条互异边。无三角形、无四圈保证根边这十二个计数没有重合。

在 q3 为中央 A 点的状态，另外三条 q 均在 B；再加 (1) 中的 r0，恰好用满 q3 的四个 B 邻位。另一方面，R3 已用满四个 A 邻位，所以 f3、ell3 都属于 C。

f3 还与 D0、r2 冲突：分别由原边 s3 t0、s3 t3 见证。第 2 节已经说明 f3 与 ell3 冲突。因此 f3 至少有三个 C 邻点

    D0, r2, ell3.

这三条边互异，亦可从 (2) 直接看出。可是 f3 对坏 Q3 至少有三个邻点，已证饱和边界引理要求它的 C 度至多二，矛盾。

因此，恰一条中央对角线属于 F 的三饱和分支也不能出现在全局最优、次级最优分区中。

## 5. 与其他分支的合并边界

`three_saturated_cross.md` 排两对角线均非 F，本稿排恰一条 F。`factor_three_saturated_dd41.md` 的双 F 对角线证明也已扩展到任意 `(4,1)`/`(3,1,1)` 混合并经独审。三项合并为：同一坏团点、同一小部的饱和私有邻点至多两个。完整接口见 `factor_saturated_private_bound.md`。

这个合并结论仍不表示整个坏团转移网络的度数至多二，因为一个坏 K5 可以从多个不同点发起交换。它也不直接消除所有坏完全分量。
