# 统一第三层目标：最小化坏圈上的阻塞事件总数

日期：2026-10-09。本文把两种零势正规化放到同一个有限字典序目标下；根代理与结构代理已分别逐节全文独审通过。整圈辐条旋转的单调性另由三方分别独立推导核验。

## 1. 分区目标及计数对象

采用围长至少六、四正则原图 G、完整二因子 F 的冲突图 H，以及已建立的 `(4,4,2)` 势分区理论。先最小化 Phi，再最小化 H[C] 的奇圈分量数。在满足这两层目标的分区中，进一步最小化

    E(A,B,C)=Σ_{v 位于 C 奇圈} ([H[A+v] 不可四色]+[H[B+v] 不可四色]).

一个双阻塞点贡献二，一个仅单侧阻塞的点贡献一，两侧都可插入的点贡献零。图有限，所以这样的三级最优分区存在。

本目标统计的是单点插入问题，没有把这些单点选项当作已经可以联合延拓。

## 2. 双阻塞点的零旋转会减少一个事件

假设坏 C 奇圈 D 上的 v 同时 A、B 阻塞。两个 O9 端点核分别使用 v 的两个原端点：一端的红伴边 a 和四条蓝邻星边全部属于 A，另一端的红伴边 b 和四条蓝邻星边全部属于 B。

这已用尽 v 的五个 A 邻点和五个 B 邻点。完整十二邻点分解所剩的两个位置，是沿 a、b 各继续一步的红边，分别记为 h、g；它们恰为 v 的两个 C 邻点。

b 属于 v 的私有 B8 组件，是其中旧 B 度四的根伴点。因此它的 profile 为

    (d_A(b),d_B(b),d_C(b))=(5,4,3).

b 的原 Fred 伴边分别是 v、g，故其 C 邻点包含 v、g。交换 v 与 b 为零势，保留全局最小 Phi。

写 b 的第三个 C 邻点为 z。交换后它的 C 邻点是 g,z。若没有补回被 v 切开的奇圈，就违反次级最优；因此 g,z 必为 C−v 同一条偶阶路径的两个端点。这里 g 已经位于 D−v，而且是这个路径的一个端点，所以 z 必是另一端 h。不能改用原 C 中某个不相关路径分量。

由此得到完整等式

    N_C(b)={v,g,h},    N_C(v)={g,h}.

零交换之后，C 只是把 D 中的 v 换成 b，其他顶点和边完全不变，奇圈数确实保持。

## 3. 其余所有坏圈点的两侧阻塞状态均保持

令新分区为 A′=A、B′=B−b+v、C′=C−v+b。

私有八点组件给出完整 B 邻域等式

    N_B(v)={b}∪X,    N_B(b)=X,

其中 |X|=4。第 2 节又给 v、b 对其余 C 点的邻域完全相同，均为 {g,h}。所以对任意集合 S⊆C−{v}，不要求 S 独立，完整诱导图

    H[B∪S] 与 H[B′∪S]

通过把名字 b 换成 v 而同构。尤其每个其余坏 C 点是否 B 阻塞都保持。A 点集未改变，所以其是否 A 阻塞也保持。

新根 b 仍然 B 阻塞，因为

    B′∪{b}=B∪{v}

是同一个顶点集合，后者正是原阻塞图。

另一方面，b 的两个 Fred 伴边在新分区中是 v∈B′ 和 g∈C′。A 阻塞 O9 的满端必须有一条 A 红伴边，所以 b 不可能 A 阻塞。

因此旧双阻塞 v 的两个事件，被新 b 的一个 B 阻塞事件替换；其余事件完全不变，E 严格减少一。这与三级最优矛盾。

**结论：三级最优分区中，每个坏 C 圈点都至少可以单独插入 A、B 之一。双阻塞点全部消失。**

## 4. 全单侧阻塞圈的四度辐条也减少事件总数

设 D 为全 B 阻塞的 C 奇圈。使用 `all_blocked_circles_joint_degree.md` 的完整端点结构：

    N_A(v_i)={a_i,a_{i−1},a_{i+1},f_i,g_i}.

其中 a_i 是自由端的 A 红伴边，三个点

    L={a_{i−1},a_{i+1},f_i}

两两不邻，并全部邻接 a_i；g_i 只可能连到这三个点。每个 v_i 都 A 可插。

假设 a_i 旧 A 度四。其 profile 为 `(4,5,3)`，且已见 C 中的 v_{i−1},v_i,v_{i+1}，所以这三个就是它的完整 C 邻集。交换 v_i 与 a_i 为零势，只在同一个 C 奇圈中以 a_i 替换 v_i，保留前两层最优。

B 点集不变。其他 C 点是否 B 阻塞均保持；新 a_i 的两个 Fred 伴边 v_i、f_i 均在新 A 中，没有 B 红伴边，所以 a_i 是 B 可插点。

现在检查 A 阻塞不能在其他 C 点处增加。新增 A 点 v_i 度四，而且其完整新 A 邻集为

    L∪{g_i},

其中 L 是一个独立三点集。任何阻塞 A8 组件中的六个四度点，其部内四邻图只有 2K2 或一个三角形加在其中一点上的悬点两种形状；这两种图的独立数均为二。因此 v_i 不能属于任何新的阻塞 A8 组件：它已经四度，不能扮演该组件的两个三度点；扮四度点又与独立三邻矛盾。

若某个未移动的 C 点 w 在交换后 A 阻塞，其 O9 核遂不含新增点 v_i。该核的全部顶点已经属于原 A∪{w}，且原冲突图中的所有边保持不变，所以交换前同一个 O9 已经证明 w A 阻塞。这里不需要该八点图在交换前已经是完整 A 分量。

新根 a_i 也 A 可插，因为

    A′∪{a_i}=A∪{v_i},

而原 v_i 已经 A 可插。

因此原 v_i 的一个 B 阻塞事件变为新 a_i 的零事件，其余坏圈点的事件数不增加，E 严格下降，矛盾。

对称论证同样适用于全 A 阻塞圈的四度 B 辐条。

**结论：在同一个三级最优分区中，全 B 阻塞圈的 A 辐条全部为三度；全 A 阻塞圈的 B 辐条全部为三度。无需分开优化两个不兼容的第三层目标。**

## 5. 两类全阻塞圈可以各自同步切开

一个全 B 阻塞圈不可能同时全 A 阻塞，因为第 2—3 节已排除双阻塞点；也可由整圈端点结构直接知道全 B 阻塞圈上的每点 A 可插。

对全部全 B 阻塞圈每圈任选一个代表，使用 `all_blocked_circles_list_extension.md` 的圈加匹配列表引理，把它们同时加入 A 后四色。对全部全 A 阻塞圈独立选代表，同样把它们同时加入 B 后四色。

这两份操作的目标部不同，各自的诱导图只受移入该部的代表影响，因此可以同时完成。C 中相应圈都被切开；其他 C 圈保持原状。

本结论处理的是这两个明确的圈类别。余下既非全 A 阻塞、也非全 B 阻塞的圈，每个点至少有一个方向可插；进一步结合 `opposite_blocked_adjacency.md`，每圈事实上至少有一个同时可插入 A、B 的点。该文逐原端点排除反向阻塞根邻接，并在第 4.1 节用零旋转排除了唯一残留的 C 三角：在没有双阻塞点的本规范化中，如果一圈也没有双可插点，则其各点只能分别为 A 单阻塞或 B 单阻塞；两类不能相邻，圈连通便迫使整圈同类，与“既非全 A 也非全 B”矛盾。

这些双向可插代表的联合延拓仍未证明；每个点的两个单点选项不能当作已经解决全部圈的同步问题。

尤其，单侧全阻塞圈被调色切开后，新的分区不必继续保持原三级最优条件。不得在没有额外证明时对余下圈反复套用原来的零势结构引理。
