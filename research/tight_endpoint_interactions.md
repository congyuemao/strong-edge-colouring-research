# 所有紧点的外端在G中构成独立集

本记录沿用 `noncritical_connectors.md` 的支撑图、缺额预算和紧点定义。以下是纯数学必要条件，不是20色总命题的证明。

设最大度至多4的简单图G中，F边的冲突图H为21色顶点临界图。删去不关联F边的顶点，令K=G\F。记d_x=d_F(x)，δ_x=4−d_x。

称p为紧点，若它在K中度为2，且两个K邻点的K度都为2。令X_p={x,x′}为p的两个F邻点，称px、px′为紧辐条。已有缺额计数给出：

1. d_F(p)=2，d_G(p)=4；两条紧辐条的H度均为20。
2. X_p内的点均有F度4；x∈X_p除p之外的所有G邻点均有F度4。
3. 不同紧点的外端组X_p彼此不交，且均不包含紧点。
4. 任意不同p、q，X_p与X_q之间的G边构成匹配。
5. H中不存在四个度均为20的顶点诱导出的菱形K_4−e。

第5项只需21临界性和菱形的度列表可染性：先染掉菱形外全部顶点，每个菱形顶点剩余颜色数不少于其菱形内度数，即可延拓。相关完整证明已在前述记录第5节给出。

**定理。** 所有紧点的外端并集⋃_p X_p在G中是独立集。即使两个紧点处于不同K分量，它们的外端之间也不能有边。

## 1. 等号预算的两个直接后果

对任意uv∈F，使用已有计数式

deg_H(uv)≤Σ_{z∈N_G(u)\{v}}d_z+Σ_{z∈N_G(v)\{u}}d_z
≤24−Σ_{z∈N_G(u)\{v}}δ_z−Σ_{z∈N_G(v)\{u}}δ_z。

若最后的缺额和已经为4，再出现一次重复计数，就会推出deg_H(uv)≤19，违反临界最小度。

**(a) 每组X_p是独立集。** 若xx′∈E(G)，则xx′∈F，因为两个外端的F度均为4。对紧辐条px计数时，p的两个K邻点已贡献总缺额4；而x′同时属于N(p)\{x}和N(x)\{p}，其关联F边被重复计数，矛盾。

**(b) K中相邻紧点p、q的外端组之间没有边。** 假设x∈X_p、y∈X_q且xy∈E(G)。这条边必属于F。对紧辐条px计数：其预算已由p的两个K邻点耗满4；另一方面，F边qy被计算两次，一次经N(p)中的q，一次经N(x)中的y。因此deg_H(px)≤19，矛盾。

## 2. 任意两个不同外端组之间均没有边

反设xy∈E(G)，其中x∈X_p、y∈X_q，p、q为不同紧点。由于外端F度为4，e=xy必属于F。

对e计数，两端的其他邻点分别包括p、q，二者各有缺额2。因此deg_H(e)≤20；临界最小度又给deg_H(e)≥20，故e的H度恰为20。

将p的另一个外端记为x′，考虑四条F边

a=px，b=px′，c=qy，e=xy。

它们彼此不同，并且H度均为20。下表逐项给出冲突情况：

| 两条边 | 冲突的理由 |
|---|---|
| a,b | 共享端点p |
| a,e | 共享端点x |
| c,e | 共享端点y |
| a,c | 由G边xy见证 |
| b,e | 由G边px见证 |

剩余一对b=px′与c=qy不冲突。验证如下：

* p、x′、q、y是四个不同点：不同外端组不交，且外端不是紧点。
* pq不是F边，因为紧点p的F邻点都具有F度4，而q的F度为2；pq也不是K边，否则第1节(b)已排除xy。
* py、x′q均不存在，因为外端除自身父紧点外的所有邻点都具有F度4。
* x′y不存在，因为X_p与X_q之间的边构成匹配，而xy已经存在。

因此a、b、c、e在H中诱导菱形，唯一缺边为bc。它的四个顶点H度均为20，与前述第5项矛盾。

结合第1节(a)，定理得证。

## 3. 比原任务更强的含义

原先欲排除的配置是“两个相邻紧点中某个外端，连向第三紧点外端”。上述定理排除了任意紧点外端之间的连接，不需要先存在相邻紧点。

结合K分量分类，它适用于P_5中点、P_6的两个中间点、以及C_3的三个点。这些紧点的全部F外端不仅互不重合，而且在G中完全互不相邻。

本定理没有排除P_5、P_6或三角K分量本身，更没有处理K为空、F=E(G)的情况。因此它仍是临界支撑图的必要结构限制。

## 4. 独立检查与先前较弱路线

证明只使用一条假设存在的外端连接xy及其三条关联紧辐条。唯一非冲突对px′、qy的所有四种潜在端点连接均已逐项排除，且四个H顶点的度20来自两个明确的满缺额预算。没有采用程序搜索或未证明的结构猜测。

此前先推导了“外端诱导图是匹配，且每个外端组至多关联一条”的较弱结论。它虽正确，但上述四边菱形直接排除了最后剩余的匹配边，因而本记录用这个更强短证取代了较长路线。
