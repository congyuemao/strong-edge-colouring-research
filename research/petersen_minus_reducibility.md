# Petersen删一条边：5/7/8列表证书与临界可约性

**已核验的计算辅助定理。** 设P为Petersen图删去一条边uv所得的10点14边图。P内部边的冲突图J有四个9度点、八个11度点、两个12度点。给这些点分别至少5、7、8种任意颜色，总能适当染色。

据此，任何最大度至多4图的21顶点临界冲突边集，其支撑图均不含诱导P。若支撑图无3/4圈，则也不能含任何非诱导的P子图，因为唯一允许补入的弦uv会产生已经排除的Petersen图。

下面明确区分纯数学归约与有限代数证书。核心非零系数由两个不同算法作了精确整数计算；不是随机列表抽样，也不是浮点近似。

## 1. 冲突图的具体结构

用五元集合的二元子集模型表示Petersen图，两个二元集不交时连边。删去12与34之间的边，其标记是遗漏元素5。

原内部冲突图为五个三点部的完全多部图。删去这条边对应的顶点后，部大小为(2,3,3,3,3)。此外，因为连接12与34的原边消失，原来在12处的两条剩余边与34处的两条剩余边之间的四对冲突消失。

把这四条边对应的特殊点记为s_0,s_1,s_2,s_3，其中s_0,s_1属于12端，s_2,s_3属于34端。它们各在不同的三点部内，诱导图为两条不相交边s_0s_1、s_2s_3。

将同部的另两点依次编号为4+2i、5+2i，i=0,1,2,3；特殊点编号为0,1,2,3；余下的二点部编号为12,13。

于是J的五个独立部是

    {0,4,5}, {1,6,7}, {2,8,9}, {3,10,11}, {12,13}。

不同部之间全部相连，但删除{0,1}与{2,3}之间的四条边。J总共74条边，点度依次为

    9,9,9,9,11,11,11,11,11,11,11,11,12,12。

独立验证器从二元子集模型重新生成14条原边，并直接按原始端点冲突定义得到J，核实它与上述描述完全相同；没有只假定多部图描述正确。

## 2. 自证的多项式系数准则

对J取图多项式

    Q(x_0,…,x_13) = ∏_{ij∈E(J), i<j}(x_i−x_j)。

它的总次数是74。设非负整数t_i的和也是74，且目标单项式∏x_i^{t_i}的系数非零，则J对任意大小至少t_i+1的点列表可染。

证明如下。将有限色池的不同颜色编码为不同整数，并从第i个列表任取t_i+1个颜色组成C_i。对每个c∈C_i定义

    D_i(c)=∏_{a∈C_i, a≠c}(c−a)。

一元Lagrange插值的最高次系数给出：对0≤r≤t_i，

    Σ_{c∈C_i} c^r / D_i(c) = 0（r<t_i），或1（r=t_i）。

对任意总次数至多Σt_i的多元单项式，除目标指数恰为(t_i)外，总有某个指数小于对应t_i：若没有，则全部至少t_i而总和不超过Σt_i，只能全部相等。因此逐变量求和会消去所有其他单项式，得到

    [∏x_i^{t_i}]Q = Σ_{c_i∈C_i} Q(c_0,…,c_13)/∏_i D_i(c_i)。

目标系数非零时，右边至少有一项Q(c)非零，表示所有邻接点颜色不同。证毕。

## 3. 精确有限证书

取目标指数

    t = (4,4,4,4,5,6,6,6,5,6,6,6,6,6)。

其和为74，逐项不超过所需5/7/8列表大小减1。计算得到严格整数等式

    [x_0^4 x_1^4 x_2^4 x_3^4 x_4^5 x_5^6 x_6^6 x_7^6
     x_8^5 x_9^6 x_10^6 x_11^6 x_12^6 x_13^6] Q = 12240 ≠ 0。

用网格C_i={0,…,t_i}时，D_i(c)=(-1)^{t_i-c}c!(t_i-c)!。故上述系数等于

    Σ_{0≤c_i≤t_i} Q(c)∏_i[(-1)^{t_i-c_i} binom(t_i,c_i)] / ∏_i t_i!。

完全精确的整数分子、分母分别为

    4223270007680138594589081600000000000
    345038399320272760995840000000000

前者除以后者恰为12240。

两份实现分别如下。

* `petersen_minus_polynomial.py`：先枚举十个普通点（五个独立二点部）的网格赋值，再用一阶矩行列式对四个特殊点的两条边分别求和。等网格独立双胞胎只取无序值对，不等值对乘2。实际枚举31500个普通点赋值。整计算使用任意精度整数，并另外用两个素数作交叉检查。
* `petersen_minus_verify.py`：不导入生成器。它重新建立原10点图和冲突关系，然后按14个变量直接回溯枚举，不合并双胞胎、不使用特殊点的一阶矩因式化。仅剪去使某一边差值为0的赋值；这些赋值对总和贡献本来就是0。最终直接累加92280个合法网格赋值，得到上述完全相同的整数分子和分母。
* `petersen_minus_independent.py`：由另一代理独立编写，从原图端点重新构建冲突图，枚举55800个普通点有序赋值并作整数求和，得到同一分子、分母和系数。该代理还逐节核验了本文件的插值证明、任意列表推论和临界应用。

结果分别保存在同名前缀的JSON中。每个网格点的权重都是显式整数，故这是一个可重复检查的有限证书。第2节纯数学准则把此有限系数证书转化为任意色池、任意指定大小列表的普遍结论。

## 4. 对临界支撑图的应用

设F按完整原图G定义的冲突图H_F为21顶点临界，并在其支撑图中假设存在诱导P。令S=F∩E(P)。

若S非空，先20染H_F−S。对于任意P内部原边e，记它在J中的度为d_J(e)。因为P诱导，其内部冲突关系与完整G一致；其完整原冲突度至多24，所以与之冲突的P外边最多为24−d_J(e)。当前已染边都在P外，因此e至少保留

    20−(24−d_J(e)) = d_J(e)−4

种颜色。三个度数档分别给5、7、8列表。可以暂时给P全部14条内部边染色，再只保留其中S的颜色，完成H_F，矛盾。

若S为空，取P中任意内部度3的点v。支撑性迫使它有唯一的一条F外伸边vx。P中其他点的F度至多2，因此v的三个内部邻点的F度和至多6。x另外三个原邻点的F度和至多12，所以

    deg_{H_F}(vx) ≤ 6+12 =18 <20，

违反21临界图的最小度要求。这里使用保守计数，已经足以矛盾。

所以任意21临界支撑图不含诱导Petersen删边块。

## 5. 无3/4圈时连非诱导子图也被排除

Petersen删去uv后，任意其他原来不相邻的点对仍在距离至多3以内，因此在无3/4圈的G中不能补上这些边。唯一可能的弦是删掉的uv本身。

这可直接在二元集模型检验：仅有的四个失去原长度2路径的非边对，是12与15、25，以及34与35、45。它们仍分别具有长度3路径，例如

    12−35−24−15，    12−45−13−25，

另两条由交换端点标签得到。其他非边点对保留原长度2路径。

因此若出现P子图，要么它诱导，要么补uv形成Petersen；后者在无3/4圈环境中本身诱导，也已由`petersen_reducibility.md`排除。

## 6. 结论的边界

这里得到的是任意规模的一个临界禁形。证明不把删去原边后的弱化冲突当作原始冲突；整个临界染色过程始终以完整支撑图为准。

这仍未证明所有最大度4图的20色命题。有限系数证书证明的是这个固定14边构形的任意列表性质，不是对一般图的穷尽验证。
