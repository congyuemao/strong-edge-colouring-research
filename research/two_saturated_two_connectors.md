# 双饱和六圈核：恰两条连接属于 F 的剩余模式

日期：2026-10-09。自主推导。本文 (1)—(5) 与状态变换更正已经根代理、反例代理分别独审通过。本文给出必要条件，尚未排除该分支。

## 1. 背景与标号

采用 `factor_two_saturated.md` 的三层最优选择：先最小 `(4,3,3)` 势，再最少 A-K5，再最大 |A|。中央匹配 qi=si ti（i 模三）在 H 构成三团，原连接为 ri=ti s(i+1)。三个同样最优的状态中，恰一个中央 qi 在 A、其他两个在 B；各 Ri 是固定 A-K4 核，Qi=qi+Ri 为当前坏团。

本稿假设 r0、r1 属于 F，r2 不属于 F。六圈因此包含红五边路径

    q0-r0-q1-r1-q2,

以及封口蓝边 r2=t2 s0。

s0 的另一 F 边记 f0，t2 的另一 F 边记 f2。沿任一这样的端点，F 延伸的后继与另一个蓝邻点处的 F 二星共三条边；其中两条属于相应 Ri，余一条记 ell0、ell2。与三饱和证明相同，fi 必冲突 elli，并且 fi 至少见到坏 Qi 的 qi 和两条 Ri 边。

其余四个中央端点的两条 F 边都在核内。每处两蓝邻点的四条 F 边中，恰两条属于相应 Ri，另外两条分别记为

    Z0  (t0 端),  X (s1 端),  Y (t1 端),  Z2 (s2 端).

每个符号代表一个二元集。所有这些余边均非 A，因为相应中央 qi 为 A 时已有 Ri 四个 A 邻点。

## 2. 精确根表

三个中央根的十二邻点分别为

    N(q0) = {q1,q2} + R0 + {r0,f0,f2,ell0} + Z0;
    N(q1) = {q0,q2} + R1 + {r0,r1} + X + Y;
    N(q2) = {q0,q1} + R2 + {r1,f2,f0,ell2} + Z2.    (1)

每一行内部为不交并。跨行不假定各 Z 或 f/ell 始终不同，只按出现位置计数。

r0 的邻点包括 q0,q1、R0 与 R1 各两条 A 边，以及

    r1,f0,Z0,X;

r1 同样包括 q1,q2、R1 与 R2 各两条 A 边，以及

    r0,f2,Y,Z2.                                      (2)

每份 (2) 共十二点，内部互异。两条 fi 都见自己的 elli；f0 与 f2 由蓝边 r2 冲突。此外 f0 与 r0 冲突，f2 与 r1 冲突。

这些表可逐六圈原端点检查。卫星允许 `(4,1)`、`(3,1,1)`、`(2,2,1)` 或匹配五团，只需中央 qi 在各自 Qi 中为孤立边。

## 3. 最大 |A| 对红连接边的约束

任一红连接 ri 都非 A。若 ri 在 B，令它唯一不冲突的中央 q(i+2) 为 A。由 (2)，它此时恰有四个 A 邻点，分别来自两个旧 A-K4 各两点。

如果 d_B(ri)=3，把 ri 零势移到 A，将两个 K4 接成非完全的九点分量，不产生新 K5，且不改变原坏团，却使 |A| 增加，矛盾。因此 ri 在 B 时本部度至多二。该状态已有两个中央 B 邻点，故 (2) 中其余六条非卫星边全部在 C。

若 ri 在 C，则它对坏 Qi 至少有三个邻点，已有饱和边界引理给 d_C(ri)≤2。

这项最大 |A| 接口由反例代理独立提出，本稿只将它用于当前分支。

## 4. 两条 r 必一 B 一 C

令 a、b 分别为 r0、r1 属于 B 的指示数，x、y 分别为 f0、f2 属于 B 的指示数，p、q 分别为 ell0、ell2 属于 B 的指示数。由中央 qi 作 A 时的 B 度四预算，(1) 给出

    |Z0∩B| = 2-a-x-y-p,
    |X∩B|+|Y∩B| = 2-a-b,
    |Z2∩B| = 2-b-x-y-q.                             (3)

若两条 r 都在 B，第 3 节立即矛盾，因为每条 B-r 的另一条 r 邻点必须在 C。

若两条都在 C，各自至多有两个 C 邻点，而另一条 C-r 已用一个。因此 (2) 中剩余五个位置至少四个为 B，合计给

    x+y+|Z0∩B|+|X∩B|+|Y∩B|+|Z2∩B| >= 8.

但将 a=b=0 代入 (3)，左边恰为

    6-x-y-p-q <= 6,

矛盾。故恰一条 r 在 B。反射六圈后，可设 r0∈B、r1∈C。

## 5. 全部已迫出的部别

第 3 节应用于 r0，立即给

    f0∈C,  Z0⊆C,  X⊆C.

代入 (3) 得

    y+p=1,  |Y∩B|=1,  y+q+|Z2∩B|=2.             (4)

r1 在 C，其 C 邻点包括 f2（若在 C）、Y 中恰一条 C 边，以及 Z2 中的 C 边。由 d_C(r1)≤2 得

    y+|Z2∩B|>=2.

结合 (4)，迫 q=0，也就是 ell2∈C，而且最后的不等式恰取等。

如果 f2∈C，那么它同时见 f0、r1、ell2 三个 C 邻点；这些边在其根邻域中互异。同时它对坏 Q2 至少有三个邻点，要求 C 内度至多二，矛盾。因此 f2∈B。再由 (4) 得 ell0∈C、|Z2∩B|=1。

最终必要模式为

    r0∈B, r1∈C, f0∈C, f2∈B,
    ell0,ell2∈C,
    Z0⊆C, X⊆C,
    |Y∩B|=|Z2∩B|=1.                               (5)

此外 f2 不邻 q1。否则由 (1) 的 q1 根表，它只能是 X 或 Y 中的一条。X 全在 C，排除；Y 又与 (2) 的 r1 根表中显式列出的 f2 分离，亦排除。

在 q2 作 A 的状态，f2 对坏 Q2 至少三邻，故 B 度至多二；此时它只有 q0 一个中央 B 邻点。在 q1 作 A 的状态，q2 重新回 B，所以这项界只给 B 度至多三。此状态下其 B 度可能是二或三；不能把前一状态的二度上界直接沿用过来。

早期研究信息中曾误称 q1 状态下 B 度恰为二，现已明确撤回。本文的 (1)—(5) 不使用这个错误等号。若剩余 B 度为三，它是否能被额外交换排除，是后续问题。

## 6. 尚缺的步骤

(5) 本身尚未矛盾。f2 在非中央端的其他 A、C 邻点仍未确定；不能把其至少两个坏 Q2 邻点当成全部 A 邻点，也不能把本部度二误当成饱和三度来强迫接收 A-K4。

当前只排除了该分支的其余 B/C 部别模式，未构造满足 (5) 的真实最优例，也未证明 (5) 必被某个更大交换打破。相同模式的左右反射仍然允许。

## 7. B 续边必须真正伸出卫星支撑

`factor_two_saturated.md` 第 4 节已独立证明：如果松端 F 续边的两个端点都在相应 Qi 的原端点支撑中，则该续边必在 C，且 C 内度至多一。证明采用第三中央点在 A 的状态；此时该续边的 A 邻点仅来自 Ri、至多三个，而它见另两个中央 B 点。若在 B，移到 A 的势差非正；零差又不会产生 K5、却增加 |A|，矛盾。

因此 (5) 中的 f2∈B 必须伸出 Q2 的原端点支撑。若 t2 在 Q2 端点核中的度数为三，它的两个卫星邻点已经把原度填满，第二条 F 边只能是核内连接，矛盾。所以 t2 的卫星核度必须为二。

按孤立 qi 的五团核分类，Q2 因而只能是 `(4,1)`，或者是 `(3,1,1)` 且其核度二的低端朝向 t2。`(2,2,1)` 与匹配型的孤立边两端核度都是三，已被排除。

Q0 的松端续边 f0 在 C，可以仍为核内续边；若它为核内，则其 C 度至多一。这不立即排除当前部别模式。
