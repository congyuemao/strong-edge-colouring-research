# O9 的全部独立点对都允许两奇圈联合修复

日期：2026-10-09。根代理与结构代理共同推导；根代理、upper_bound 代理均已完整独立审读本文通过。本文不假设一般的两点联合阻塞都等于 O9；只处理确实出现 O9 的情形。

## 1. 背景和准确结论

沿用 `factor_girth_six_ten.md`：G 四正则、围长至少六，F 为完整二因子，H 是 F 在完整原 G 中的冲突图。取 `(4,4,2)` 全局最小势分区 A、B、C，再使 H[C] 的奇圈分量数最少。A、B 的内部最大度至多四，C 的至多二。

用下列标号表示 O9：

* a,b,c,d 构成 K4；
* a,b,u,v 构成第二个 K4；
* c,d,w,z 构成第三个 K4；
* x 邻接 u,v,w,z；
* 没有其他核内边。

假设这九点在 H 中诱导 O9，恰有两点 p,q 属于 C，且分属两个不同的 C 奇圈，其余七点都属于 A。

**命题。** 可以重新分配这九点中的若干点，得到两个四色可染的部 A*、B*，其余顶点恰为原来的 `C−{p,q}`。因此两个指定的原 C 奇圈同时被切开，不产生新 C 圈。若原 C 恰有这两个奇圈，则 H 十色可染。

最终 A*、B* 只要求四色可染，不声称仍保持原最大度或最优势。这一区别对多个奇圈的继续同步很重要。

## 2. 需要的既有纯引理

以下接口均已有独立证明。

1. 每个坏 C 奇圈上的点三部邻数为 `(5,5,2)`。若一个 A 内四度点邻接这样的点，则其邻数为 `(4,5,3)`，两点交换零势。交换后的分区仍满足两层最优条件；否则已与原最优性矛盾。
2. 一个旧 A 内四度点不能邻接两个不同的坏 C 奇圈。见 `factor_girth_six_synchronization.md` 第 2 节。因此上述零交换保留另一个原奇圈；换入 C 的点必须位于某个新的奇圈上，以补回被切开的那个奇圈。
3. 坏 C 圈点 r 单独插入 A 若不能四色，则其五度高点成团，唯一五临界核为 O9，且 r 在核内为高点，使用全部五个 A 邻点。见 `five_critical_high_clique_two.md`、`five_critical_high_clique_four.md`。B 同理。
4. H 的每个 K4 恰由一条蓝边两端的两个完整红二星组成。这里红边是 F，蓝边是 G−F；原点处的完整红二星是该点关联的两条 F 边。两个 K4 若共享两点，这两点必为同一个完整红二星。
5. 对一条原红边，十二个 H 邻点在无三角形、无四圈条件下互异：两端各有一个红伴边、两个蓝邻点的四条红边，再加沿两端红伴边各继续一步的两条红边。

接口 3 和 4 的一个具体推论反复使用：若 r 单独插入 B 失败，则它在某个原端点处的红伴边、以及该端点两处蓝邻点的四条红边，全部属于 B。这五点恰好用满其 B 邻点。

## 3. O9 几何与三个点对轨道

由原三个 K4，四对红边

    {u,v}, {a,b}, {c,d}, {w,z}

都是完整红二星。设其原中心依次为 G0、B0、E0、H0，则有蓝三边路径

    G0—B0—E0—H0.                                      (1)

四个中心互异，因为它们对应的四对 F 边两两不交，而一个原点的完整红二星唯一。

O9 的独立数为二。若独立点对不含高点 a,b,c,d，就只能各从 u,v 和 w,z 选一点；若含高点 a，其非邻点只有 x,w,z，而这三个点形成三角形。利用核的对称性，独立点对恰有三种轨道：

    LL: {u,w};    HL: {a,w};    HC: {a,x}.

两个来自不同 C 分量的点当然不相邻，因此只须处理这三种。

## 4. 共同的 B 部选择引理

在 HL 或 HC 情形中，先比较两个分区：原分区，以及交换 a、b 后的分区。此处 a∈C、b∈A，且 b 在 A 中已有完整四邻点 `{c,d,u,v}`，所以其旧 A 度恰为四，交换零势。

两个状态分别以 a 或 b 为坏 C 圈代表。B 始终未变，且

    d_B(a)=d_B(b)=5.                                  (2)

另一个指定的 C 奇圈保持不变。

**至少一个状态的代表可插入 B 四色。** 把原红二星写为 `a=sα, b=sβ`。如果原状态 a 插入 B 失败，由于 s 处的另一红边 b 在 A，其 B 核只能使用另一端 α。因此 α 的另一红伴边和 α 两处蓝邻点的四条红边全部在 B，恰为 a 的五个 B 邻点。

若交换后的 b 插入 B 也失败，同理 β 的另一条红伴边 h_b 属于 B。原边 b 使 h_b 与 a 冲突；但是 h_b 是根边 a 沿 s 端红伴边 b 再继续一步的邻点，和刚才 α 侧五点互异，见接口 5。这使 a 至少有六个 B 邻点，违反 (2)。

故可以在两个零势相关状态中选择一个，使当前 C 代表可插入 B。接下来证明另一指定代表在这两个状态中都可插入 A。

## 5. HL：高点 a 与相对低叶 w

此时 a,w∈C，其他七点属于 A。c,d 各已有三个 A 核邻点，并且同时邻接 a、w 两个不同的坏 C 圈，所以由接口 2，它们的旧 A 度恰为三。交换 a、b 时它们都失去一个、得到一个 A 邻点，度数仍为三。

在两个状态中，w 的五个 A 邻点均可写为

    c,d,z,x,e,

其中 e 是核外的第五点：w 不邻接 a,b，所以这组邻点不随交换改变。

假设某一状态中 w 不能插入 A。由唯一单点核接口，w 必是新 O9 高点；c,d 的 A 度只有三，插入后至多四，不能成为高点。因此新核的其余三个高点只能是 z,x,e；它们与 w 构成 K4。

这个 K4 的红二星分拆是 `{w,z}` 和 `{x,e}`。一种直接理由是：旧 K4 `{w,z,c,d}` 已经给出完整二星 `{w,z}`，而新 K4 与它共享 w,z；也可以用完整二星的唯一性。因而 w 在新 O9 中与 z 配对，其另外两个低邻点就是 c,d。

令 h 为该状态中仍属于 A 的 a,b 之一。在插入 w 后，c,d 的完整 A 邻集分别是

    {d,z,w,h},    {c,z,w,h}.

所以新 O9 的低中心只能是 h。h 的完整 A 邻集是 `{c,d,u,v}`，因此另一对低叶必为 u,v，新核再迫一个 K4 `{u,v,x,e}`。

设完整红二星 `{x,e}` 的原中心为 P。新两个 K4 `{w,z,x,e}`、`{u,v,x,e}` 给蓝边 H0P、G0P；与 (1) 合成蓝五圈

    G0—B0—E0—H0—P—G0.

五个中心互异，因为五对红边两两不交。这违反 G 的围长至少六。

因此两个状态中 w 都可插入 A。选择第 4 节中代表可插入 B 的状态，将该代表插入 B、w 插入 A，两部独立四色，最后 C 恰为原 `C−{a,w}`。HL 得证。

## 6. HC：高点 a 与低中心 x

此时 a,x∈C，其他七点属于 A。u,v 各同时邻接 a、x 两个不同的坏 C 圈，所以旧 A 度至多三。交换 a、b 时，u,v 都同时邻接两者，故其 A 度保持不变；交换不改变 x 的 A 邻集，因为 x 不邻接 a,b。

在两个状态中，x 的五个 A 邻点均为

    u,v,w,z,e,

其中 e 是核外第五点。如果 x 插入 A 失败，u,v 在插入后至多四度，不能成为新 O9 高点。因此另三个高点必是 w,z,e，新高 K4 为 `{x,w,z,e}`。

旧的 w,z 是完整红二星，所以新高 K4 的另一红二星是 x,e。唯一 O9 中 x 的另一对低邻点只可能是 u,v，于是另有 K4 `{x,e,u,v}`。这两个新 K4 又给蓝边 H0P、G0P，与 (1) 组成相同的蓝五圈，矛盾。

所以两个状态中 x 均可插入 A。结合第 4 节选择 a 或 b 可插入 B 的状态，最终 C 恰为原 `C−{a,x}`，HC 得证。

## 7. LL：两个相对低叶 u,w

现在 u,w∈C，其他七点属于 A。a 的旧 A 完整邻集为 `{b,c,d,v}`，故旧 A 度为四；交换 u、a 是零势。新分区仍满足两层最优，w 的原奇圈保持不变，而 a 位于补回的一个新奇圈上。

原九点仍诱导同一个 O9，但其属于 C 的两点变为 a,w，属于第 5 节已经证明的 HL 情形。因此在新分区中应用 HL 修复，最后 C 为

    ((C−{u})∪{a})−{a,w}=C−{u,w}.

这样同时修复了两个原奇圈。其更直接的双旋转证明见 `joint_o9_two_repair.md`，与本节一致。

## 8. 结论的边界和下一接口

三种独立点对已全部覆盖，所以任意以两个不同坏 C 奇圈代表补出的 O9，都有上述两圈修复。该结论不要求预先指定两代表各自是否可插入 A；证明本身在需要时建立了相应单点可插性。

仍有两个实质缺口：

* 对一般两个各自可插入 A 的代表，联合失败的五临界核未必是 O9。联合图最大度仍至多五，但其高点未必形成一个团，不能直接应用唯一高团核分类。
* 修复后的 A*、B* 只知四色可染，不一定仍是最优 `(4,4,2)` 分区。若还有其他奇圈，不能未经证明反复调用本文。

因此本文给出完整的 O9 两代表局部修复，而不是一般围长六的十色定理。
