# 私有八点组件上的任意多圈同步零旋转

日期：2026-10-09。以下为纯接口推导，使用已独立核验的单点阻塞八点组件刚性；结构代理已逐节全文独审通过。结论是保留最优分区的同步正规化，不是把多个单点延拓自动拼成完整着色。

## 1. 阻塞根与真正的孪生伴点

沿用围长至少六、完整二因子冲突图 H 的最优 `(4,4,2)` 分区 A、B、C。坏 C 圈点 r 若单独插入 B 失败，其唯一 O9 核删去 r 后的八点图 D 是整个 B 连通分量；每个这样的 B 分量至多对应一个坏 C 阻塞点。

O9 标号取高团 r,b,c,d，另有 K4 rbuv、cdwz，低中心 x 邻接 u,v,w,z。则

    N_B(r)={b,c,d,u,v},   N_B(b)={c,d,u,v}.

第二个等号是完整 B 邻集，不只是核内邻集，因为 b 旧 B 度恰四。r,b 在原 F 中是一个完整二星。令 X={c,d,u,v}，于是 r 和 b 相对于其余 B 顶点是真正的孪生点。

旧 b 邻接坏圈点 r，所以完整三部邻数为 `(d_A,d_B,d_C)=(5,4,3)`。交换 r,b 的势差为零；交换后的 B 图只把名字 b 换成 r。A 集合不动。

## 2. 来自不同坏圈的任意多个交换互不干扰

选择 r_1,…,r_t，分别来自不同的坏 C 奇圈，并且都 B 阻塞。记其私有 B8 分量为 D_i、Fred 伴点为 b_i。

这些分量不同，因此 b_i 两两不邻。r_i 两两不邻，因为它们在不同 C 分量。若 i≠j，b_i 也不邻 r_j：一个旧 B 四度点不能接触两个不同坏 C 奇圈，而 b_i 已邻 r_i。

所以任意两组移动点 `{r_i,b_i}`、`{r_j,b_j}` 之间没有 H 边。每对单独交换的势差是零，它们的势差可以直接相加。因此任取指标子集 I，同时交换所有 r_i,b_i，仍是全局最小势分区。

还需检查次级奇圈数，而不能只凭零势假定。写

    N_C(b_i)={r_i,s_i,t_i}.

单独交换时，已证 s_i,t_i 必是 C−r_i 中某条偶阶路径 P_i 的两个端点，否则不能补回被切开的奇圈。该路径可以是原 r_i 圈删点所得，也可以是原 C 的另一个路径分量；它不属于任何其他旧 C 奇圈。

同时交换不会删掉 P_i 上的点，因为 b_i 不邻其他被选 r_j，而 P_i 若来自旧路径分量本来就不含坏圈代表。因此每个 b_i 仍闭合 P_i。不同 P_i 不可能相同：若两者相同，它们的端点原本度一，同时接两个 b 就升为三，违反新分区仍为最小势所保证的 C 最大度二。两个不同路径分量也不相交。

故每个被切开的原奇圈都由一个不同的新奇圈补回，总奇圈数不变。所有任意子集的同步交换都保留原两层最优性。

## 3. 对整个另一部插入问题的保留

同步交换不改变 A。B 只逐个把 D_i 中的 b_i 换成 r_i，且在其余 B 顶点上的邻域完全相同。因此新旧完整 B 图同构。

更强地，令 S 为其他未选旧坏 C 奇圈中的任意点集；不要求 S 内部独立。每个 r_i 与 S 不邻；每个 b_i 与 S 也不邻，仍因旧 B 四度点不能跨坏圈。因此在相同的逐点重命名下，完整诱导图 B∪S 也保持同构。

这保留其他圈的任意联合 B 插入问题，不仅保留每一个点的单独可插性。

## 4. 可独立让所有选中代表 A 可插

固定一对 r_i,b_i。在原状态 r_i 属于 C、b_i 属于 B；交换后反之，A 完全相同，两者的 A 邻数都为五。

它们不可能分别在这两个状态都 A 阻塞。若都失败，各自 A-O9 的满端不能位于它们共享的 Fred 二星中心，因为另一条红伴边在 B；所以必须分别使用两个远端。第二条红边远端的 A 伴边，又通过这两条 Fred 伴边关系成为第一条红边的第六个 A 邻点，和其远端完整五个 A 邻点互异，矛盾。这正是已有远端伴边引理。

所以每一对至少有一个 A 可插的选择。由于 A 本身在所有同步交换中不动，这些选择可以彼此独立作出，再一次性实施相应零旋转。

最终仍是两层最优分区；每个选中的新 C 代表都 A 可插、B 阻塞；其他未选圈的 B 联合插入问题保持不变。

## 5. 五点覆盖约束并未因正规化消失

`blocked_eight_uniform_extension.md` 给出了 D_i 的精确四染条件：若所有拟插入 B 的外点共用颜色 α，则 D_i 可延拓当且仅当它们没有覆盖其五点低集 `{u,v,w,z,x}`。

本文的同步旋转只替换高伴点 b_i 与阻塞根 r_i，这五个低点完全不动；其他圈的全部邻接关系也不变。因此原来存在的五点覆盖仍然存在。同步正规化不能被误当作已经满足全部覆盖条件。

同样，最终许多代表都单独 A 可插，不意味着它们可以一起插入 A。三个以上代表可能让旧 A 三度或更低度点升到超过五度，两代表的临界核至多四十四点界也不能直接覆盖这种情况。

新增的严格结论是：上述私有阻塞组件的代表二选一，可以在任意规模上同步、保持最优性，并保持另一个方向的整个联合插入问题。剩余困难被集中到选择后的联合 A 染色以及五点覆盖等相互作用上。
