# 强边二十色研究总报告

归档日期：2026-10-09。状态：按用户要求暂停，原命题未解决。

## 1. 问题与记号

G 是有限无向简单图，最大度至多四。若两条不同边共端，或者某条原边连接它们的两个端点，就称这两条边冲突。强边染色要求冲突边异色。

对候选边集 F，记 H_F 为以 F 为顶点、以冲突为邻接的图。冲突始终按照完整 G 判断，不能删掉 F 外的连接边后再判断。原命题等价于对所有这样的 G，整个边冲突图可二十色。

用户在继续研究时给定一般最优界位于二十至二十一之间；本项目没有独立复现所给二十一色上界。最初独立得到的二十二色上界保留为历史证明，不作为当前数值进展。

## 2. 研究基准与范围调整

最初工作完全从定义出发，包括端点计数、临界子图、列表染色、交换法和本地程序。后来用户要求以经典分数 Reed 定理及已得强团界为基准：无三角形、无四圈时，任意 F 的分数冲突色数至多十六；若 F 内部最大度至多二，则至多九。

因此，早期独立得到的加权十九和十界已被更强基准涵盖，保留其证明与方法但不再作为突破，也不将分数界自动取整成整数界。

当前主线是四正则、围长至少五的 G 中，任意完整二因子 F 是否都使 H_F 十色可染。如果成立，两个二因子使用不交色板可以处理相应原图；这仍不自动完成含短圈等其他一般情形。若任意因子命题失败，备选方向是特殊因子分解和跨因子重着色。本次未找到任意因子十色的反例。

## 3. 一般最大度四图的已有成果

### 3.1 强团与诱导匹配

二十条两两冲突边的等号情形被识别为孤立的五圈双点吹胀分量。该构造也给出严格二十色下界。高冲突度边所在强团还有更小的阈值上界。

通过私有邻域交换和双计数，已证明任意 F 满足 `|F|≤20ν_s(F)`，其中 ν_s 是最大两两不冲突边集大小；有相应多项式局部算法。更强形式为 `2|F|≤39ν_s(F)+t`，t 计数 F 完整包含的孤立紧二十分量。它们是独立集打包保证，不能据此构造二十个独立集覆盖全部 F。

证明见 [打包定理](../research/packing_private_cliques.md)、[二十团刚性](../research/clique20_rigidity.md) 和 [成果登记表](RESULTS.md) 的阈值证明链。

### 3.2 临界反例规模与可约块

已排除至多四十一条原边的反例；因此若存在二十一临界冲突边集，至少含四十二条边。按原顶点数，这覆盖至多二十点的图。证明利用临界补图的匹配分解及四十一点的有、无三角形两分支。

若存在极小原反例，还必须满足若干连通性、边割、支撑和缺额度条件。已得到 K3,3 块、Petersen 块、Petersen 删一条边块的相应可约性。最后一项使用自证的多项式插值准则和精确整数系数 12240，三套程序独立计算一致。

这些条件排除了具体结构，没有证明所有剩余图为空。另有计算辅助的临界强团至多十五界，其有限模型和覆盖范围单独保存。

## 4. 高围长二因子十色主线

### 4.1 小阶与完整子类

任意最大度至多十二、团数至多五、至多二十二点的图可十色，至多十九点时可九色。因此当前因子十色反例至少需要二十三个原顶点。

两类从十一色、十二色因子基图出发的高围长有限覆盖已获得任意阶十色证明，故不再在这些已关闭的族中无目标扩样。指定低阶覆盖的精确枚举和独立审计仍保留。

红五圈按蓝匹配组成圈链的一类图已经精确求色：四层情形需要七色，至少五层按扭转置换需要五或六色。另有只需六色的无限族却不能作 `(5,5)` 度分区，说明某种过强分区目标会失败，而非十色命题失败。

### 4.2 围长五的 `(4,3,3)` 分区

这里把 H_F 的顶点分为 A、B、C，最小化带部容量的势，再按坏团数量及类型逐层选优。坏 A-K5 的固定点向同一小部的饱和转移邻点至多二，三个原端口分支均有完整证明。强五团的森林类型和五圈类型也已分类。

在全硬五圈挂边这一类中，已证明任意多个坏团可以同步修复，包括外伸挂边及初始位置不一致的情形。关键新接口是带私有三角的整数三染色定理。

尚未闭合的部分包括其他森林型坏 K5、原 B/C-K4，以及转移链的全局兼容性。小部 K4 路线已得到固定 A 的六邻闭包六染、四邻出口零转移和红五圈平衡停止核排除，但五邻候选不能任意选取。保存的 O9 与非相邻双高九点核都给出真实原端点的局部反证；它们没有最优分区证书，不能用来否定全部出口。

### 4.3 围长六的 `(4,4,2)` 分区

H_F 十二正则且无 K5。最小势使 A、B 内度至多四、C 内度至多二；再最少 C 奇圈。坏圈点的三部度为 `(5,5,2)`。单点插入失败由唯一九点高团临界核 O9 控制，故每个坏圈至少有一个可向某部单点插入的点。

后续把“实际单点阻塞”和“原端点五邻全部落入同一部的满端”分开。第四层有限极值规范化已证明：

1. 一个坏圈点不能同时有满 A、满 B 端。
2. 相反满端的两个坏圈点不能相邻。
3. 同向满端根的自由端投影全由蓝边连接；三个连续同向满端根的中间辐条必须恰为三度。
4. 整圈同向满端或连续七点同向满端的一批圈，可以同步列表修复。
5. 其余圈各有一个不具任何满端、因而双向单点可插的代表。

完整证明见 [满端规范化](../research/full_end_normalization.md)。问题转为距离较近的这些代表能否统一分配、联合四色。单点可插入绝不等于联合可插入。

### 4.4 联合临界核与同步成果

已严格构造九点、十三点、删点七圈双吹胀等不同五临界核，并给出其中若干核的四正则高围长原图实现。它们揭示“所有联合失败核只有 O9”的推断错误。

O9 的全部两代表轨道、指定十三点核的两代表位置以及若干递归附件族已有双圈修复。一般两代表联合失败有至多四十四点的临界见证；该规模界不是对全部四十四点图的穷举。

无满端代表的 LL-O9 搭档关系是匹配；十三点型中“共同 P3、各自 K2、两个 K2 合成旧 K4”的更强搭档关系也已证明是匹配。两类根在同一部的邻域形状互斥，因此每部合起来仍是匹配。两个部的匹配并图可二分，从而可一次分配任意数量代表，避开全部 O9、指定两代表十三点核及被该配置涵盖的三代表类型。

十三点核独立数为三。剩余三代表类型可以经过一、两次零势交换归约到搭档型，但只证明保持前两层最优，未证明保持全部规范化统计和已有分配，故一般同步仍缺。

另一个严格充分条件是：各自 A 可插的代表在完整 H_F 中两两距离至少十七，则任意多个都可同时插 A 后四色。证明由低块端口上界和互不交半径八球下界矛盾完成；尚不能保证每圈都能选到这样远的代表。

### 4.5 新的 `(5,4,1)` 匹配端点路线

该分区把 C 压为匹配及孤点。最小势再最少 C 边数时，每个坏边端点三部度为 `(6,5,1)`；每个端点都能单独插入 A 后五染。关键是独立证明的高点成团定理：`K_k-free、Δ≤k+1、全部(k+1)度点成团 ⇒ k色`。

两代表联合失败的六临界核最初界为四十一，随后利用低五度 K4 块不共割点、孤立低代表扣除、度数奇偶及零旋转约束，已严格缩到三十二；只要某代表在核中降为五度，核至多二十九。证明稿及整数表在暂停前已读审并复跑。暂停前最后提出的二十八点加强只记为未审核笔记，未提升为正式成果。

任意多端点的二选一容量约束仍未解决；即使控制联合最大度，六度高点也不必成一个团，不能直接套单点五染结论。

## 5. 可独立使用的辅助定理

- k≥4 的私有团染色定理：无 K_(k+1)、最大度≤k+1，每个高点带 k−1 个低邻成团，且每个低邻只关联该高点，则可 k 染。不要求高点独立，也不需要排额外共同低邻。删掉唯一高邻条件有明确二十五点五色例。
- k=3 的私有三角版本另需私有对没有其他共同邻；该条件不可草率删除。五圈替换为三角形的颜色等价已逐一检查全部二十七种边界赋色。
- 最大度五、无 K5、全部五度点构成至多三点团时可四色。恰有两个不相邻高点则存在九点五临界核及围长五原端点实现。
- 若超边至少有两个点、关联正整数权总至少三、每点总关联权至多五，则可弱四色。另有适用范围明确的混合约束和概率接口；它们尚未处理全部低块树。

## 6. 计算证据与已失败方法

计算分为四类：具体色表和匹配证书；明确有限搜索空间的穷举；原端点实现及其完整二因子补全；不包含图枚举的整数表或多项式系数核算。四类不能互相替代。

已发现的失败包括：一次 Kempe 交换可能停滞；固定外部染色的局部列表延拓可能失败；局部单点稳定未必是真正最小势；某些饱和邻容量推断遗漏孤立点；纯新端口模型的否定结果不能外推允许额外外边的模型。精确更正集中见 [审核与更正](AUDIT_AND_CORRECTIONS.md)。

本次归档没有再次批量启动搜索或重证旧界。文件完整性、语法和格式检查与数学真伪检查分别记录。
