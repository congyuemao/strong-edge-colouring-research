# 审核状态与重要更正

本记录保留已经发现的推断错误、被更强结果覆盖的旧界及局部计算的适用边界。原始稿未作历史清洗；本文件与成果登记表提供统一解释。

## 证据状态

| 状态 | 含义 | 不能推出什么 |
|---|---|---|
| 完整证明稿及内部独立复核 | 已有逐步论证，研究中另一路检查过关键步骤 | 不表示外部同行评议或形式化验证 |
| 计算辅助普遍结论 | 有证明把问题归约到明确有限空间，程序验证该空间 | 不覆盖归约之外的图 |
| 有限搜索或显式证书 | 某个图、指定族或有限枚举范围已检查 | 不自动外推所有图 |
| 局部原端点实现 | 指定冲突核确实来自合格原图及因子 | 不自动实现要求的全局最优分区 |
| 待审核笔记 | 暂停前的候选公式或代理消息已保存 | 不登记为定理 |

内部复核人员是同一研究过程中的根代理和独立子代理，均属 AI 协作；文件中“独审”应据此理解。程序退出成功只在阅读其覆盖范围后才作为对应结论的证据。

## 主要更正和关闭的路线

1. **加权19/10不是新数值突破。** 用户提供分数Reed基准后，分数16/9已更强。旧稿保留，未继续以弱界为成果目标。
2. **单点可插与多点联合必须分开。** `(4,4,2)` 中每坏圈有单点出口，不能据此宣布十色。修复后的部可能不再满足最优分区度数，不能无证明地逐圈迭代。
3. **联合五临界核不只有O9。** 十三点核和C7双吹胀核已有原端点完整实现。相应局部修复不等于所有核分类。
4. **十三点核可含三个代表。** 独立数为三；两代表搭档匹配只覆盖明确配置。剩余三代表轨道的零旋转尚未证明保持第三、第四层最优或全批次分配。
5. **核内度不等于完整旧部度。** 抽取临界子图后顶点可能降度；不能直接把核内三度当旧三度，也不能假设插入根保留全部邻点。
6. **双高点的相邻条件真实必要。** 失败插入根在临界核中可由五度降成四度，另两个非邻高点仍五度。不能用高点数奇偶推断必有三个旧四度邻点。九点核和原端点证书已保存。
7. **541三坏边容量分类曾漏原C孤点。** A四度点的四个C邻点除了(2,1,1)分布，还可能三个坏边单例加一个旧C孤点。后者给三元条件，已在正式稿更正。
8. **平均负载不保证整数选择。** 每匹配边随机取一端所得期望度上界，不证明所有点同时满足容量，更不保证最终五色。
9. **局部单点稳定不是真正全局最小势。** 一份268点构造的四中央状态虽单点稳定，已发现37个负势双交换，故不能用作最优分区反例。
10. **新旧坏团的私有性不能跨一次转移照搬。** 曾推断matching坏团转移后必变软型，因错误把旧团删根当新根私有团而撤回。
11. **全阻塞圈自由端连接不能先验视为蓝色。** 原先快捷判断撤回，后来用A度计数严格排红连接，得到现在可用的蓝投影结论。
12. **私有三角定理可删高点独立条件，但不可同时删额外共同邻条件。** 后者有反例。k≥4版本另有更强证明，不能混用两种范围。
13. **六点连续段的列表弱化有反例。** 三组P4加匹配产生九奇圈二列表障碍，因此不能仅用“中心匹配独立”把七点条件降为六。
14. **小部K4的平衡模型有三个搜索版本。** 最初只检查部内度时matching有正例；加入每点十二度、无负单移的必要条件后，纯fresh模型121个F选择、1070个三角尝试均无正例。增加一条明确外蓝边的单独20个模型全部局部可行。三个范围已在历史JSON分开保存。
15. **两个局部度表可补齐，不等于共同原图可补齐，更不等于最优势实现。** 所有相应搜索正例按这一级别标注。单独的有限正规补全引理只保持原端点核，不保持A/B/C最优性质。
16. **四候选整体K5障碍的DD分支尚未排尽。** 最后消息中“D均C可回旧全C矛盾”因允许外续边属A而撤回，没有写成总定理。
17. **强团上界不是色数上界。** 同样，诱导匹配数量保证、分数染色界、局部邻域染色界都不自动转为全图整数色数。
18. **方法反例不是命题反例。** 不能(5,5)度分区的族、局部列表失败、单次Kempe停滞和显式五临界子核，均未给出需要十一色的合格因子或需要二十一色的原图。
