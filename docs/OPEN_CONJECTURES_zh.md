# 未证明命题总表

**整理日期：** 2026-11-04。**范围：** MANUSCRIPT 第 9 节和 NEW_DIRECTIONS 中所有还没有证明的命题，以及已被推翻的形式。证明和数据的细节在出处，这里只放陈述、蕴含关系、证据的覆盖范围。

**用词。** "未打穿"只表示对抗搜索没有找到反例，不表示可能为真。"局部无解"指在端口松弛下，只看树状球证不出来，这是关于方法的结论，不是反例。

记号：L² 是 L(G) 的平方，N(e) 是 e 的已染冲突边，f_p 是单重颜色 p 唯一的成员。(a, b) 在 f 处**可分离**：没有 (a, b) 分支同时含 f 的 a 色邻边和 b 色邻边。e **一步卡死**：e 被堵住，且 e 处没有可分离对。

## 6. 证据覆盖的缺口

1. **k ≥ 1。** 第一组的全部对抗都只有 k = 0。
2. **规模和时间。** 对抗只到 n ≤ 400，每次 90–180 分钟，都是局部搜索。n = 400 没有 KIL₂ 终态就进不了卡死。
3. **围长。** 有梯度的 GPU 对抗只在围长 5、6 上有效。围长 8 的冷启动进不了卡死，比较不出围长的影响。
4. **精确判定。** 只有 n = 14、20、24 的 19 条边判定到"一次改色就够"（exp34）；n = 40 的切块 SAT 没跑完就停了，它问的又只是已被推翻的一步形式。
5. **没有存档。** 11.26 的低值状态没有保存，要继续打得重跑。
