## 当前最重要的进展

- 高围长二因子整数十色是当前主线，仍未完成。分数十六与九是已接受的研究基准，原加权十九与十不再作为数值突破。
- 围长至少六时，四层最优分区可规范化满端结构；整圈或连续七点同向满端的一批奇圈可以同步修复。余下圈可选无满端代表。
- 九点障碍和十三点核的指定两代表搭档关系是匹配，可一次分配任意多个无满端代表以避开这些配置；这不排除其他临界核及十三点核的剩余三代表情形。
- 另一条 `(5,4,1)` 分区路线中，每个坏匹配端点可单独插入。两代表联合失败必有至多 **32 点**的六临界核；这是必要条件，不是已穷尽搜索。
- 一般问题已得到若干严格局部成果：二十边强团的等号分类、至多四十一条边时二十色、Petersen 删边块的列表可约性，以及最佳常数二十的诱导匹配打包界。这些都不足以推出一般二十色。

## 证据如何解读

“已内部复核”表示证明稿经研究过程中的另一路推导或代理检查，并保留可追溯记录；不表示已通过形式化证明系统或外部同行评审。计算证书只支持其明确列出的有限实例或数学归约范围。未审核想法单独保存在交接记录，不列为定理。

研究最初不查阅文献。用户后来明确授权核查强团界七与五的先例，并提供分数 Reed 基准。有限文献核查见 [原始记录](research/high_girth_clique_literature.md)：界七已有先例，界五未确认相同先例，不能据此声称新颖；未借阅整数二十色的已有证明。
